INSTRUÇÕES DETALHADAS

PASSO 1: IDENTIFICAÇÃO DE TEMAS PRINCIPAIS

Leia todo o conteúdo e identifique os temas principais seguindo este processo:

Liste todos os capítulos, seções e subseções do livro


Para cada seção, identifique o assunto central em uma frase


Agrupe seções que tratam de assuntos relacionados


Nomeie cada agrupamento com um tema abrangente


Você deve ter entre 3-8 temas principais no total

Exemplo:

Capítulo 1: "Introdução à Programação" → Tema: Fundamentos


Capítulo 2: "Variáveis e Tipos" → Tema: Fundamentos


Capítulo 3: "Estruturas de Controle" → Tema: Lógica de Programação

PASSO 2: IDENTIFICAÇÃO DE SUBTEMAS

Para cada tema principal:

Liste todas as seções que pertencem a esse tema


Identifique padrões ou categorias dentro dessas seções


Agrupe seções relacionadas em subtemas


Cada tema deve ter 2-6 subtemas

Exemplo para Tema "Fundamentos":

Subtema 1: "Conceitos Básicos" (agrupa: O que é programação, História)


Subtema 2: "Ambiente de Desenvolvimento" (agrupa: Instalação, Configuração)

PASSO 3: EXTRAÇÃO DE CONCEITOS-CHAVE

Para cada subtema, identifique os conceitos-chave:

Leia o conteúdo completo do subtema


Liste todos os termos técnicos, definições e ideias principais


Selecione os 5-7 conceitos mais importantes (não mais que isso)


Para cada conceito, escreva uma definição de uma linha

Critérios para selecionar conceitos-chave:

É um termo técnico específico?


É mencionado múltiplas vezes?


Outros conceitos dependem dele?


É necessário para exercícios ou aplicações práticas?

PASSO 4: IDENTIFICAÇÃO DE RELAÇÕES HIERÁRQUICAS

Para cada conceito identificado, determine suas dependências:

Pergunte: "Para entender este conceito, o aluno precisa saber o quê antes?"


Liste os conceitos pré-requisitos


Se um conceito não tem pré-requisitos, marque como "fundamental"


Crie uma ordem sequencial respeitando essas dependências

Exemplo:

Conceito: "Loop For"

Pré-requisitos: "Variáveis", "Operadores de Comparação", "Blocos de Código"


Conceito: "Variáveis"

Pré-requisitos: nenhum (fundamental)

PASSO 5: CLASSIFICAÇÃO POR NÍVEIS COGNITIVOS

Para cada conceito, classifique segundo o nível cognitivo usando esta escala:

NÍVEL 1 - LEMBRAR (memorização básica):

O conceito requer apenas memorizar uma definição ou fato?


Exemplo: "Variável é um espaço na memória para armazenar dados"

NÍVEL 2 - COMPREENDER (explicar com suas palavras):

O conceito requer entender como algo funciona?


Exemplo: "Como uma variável armazena diferentes tipos de dados"

NÍVEL 3 - APLICAR (usar em situações práticas):

O conceito requer aplicar conhecimento em um problema?


Exemplo: "Usar variáveis para calcular média de notas"

NÍVEL 4 - ANALISAR (decompor e examinar partes):

O conceito requer comparar, contrastar ou examinar componentes?


Exemplo: "Comparar diferentes tipos de loops e quando usar cada um"

NÍVEL 5 - AVALIAR (julgar e criticar):

O conceito requer avaliar qualidade ou fazer julgamentos?


Exemplo: "Avaliar qual estrutura de dados é mais eficiente para um problema"

NÍVEL 6 - CRIAR (produzir algo novo):

O conceito requer criar soluções originais?


Exemplo: "Projetar um algoritmo completo para resolver um problema complexo"

PASSO 6: ESTIMATIVA DE COMPLEXIDADE

Para cada conceito, estime a complexidade considerando:

COMPLEXIDADE BAIXA:

Conceito tem definição clara e direta


Poucos ou nenhum pré-requisito


Pode ser explicado em 2-3 parágrafos


Exemplos são simples e diretos

COMPLEXIDADE MÉDIA:

Conceito requer explicação de múltiplos aspectos


Tem 2-3 pré-requisitos


Precisa de 4-6 parágrafos para explicar


Exemplos requerem múltiplos passos

COMPLEXIDADE ALTA:

Conceito é abstrato ou multifacetado


Tem 4+ pré-requisitos


Precisa de múltiplas seções para explicar


Exemplos são complexos e requerem contexto extenso

REGRAS IMPORTANTES

Seja exaustivo: não omita conceitos importantes


Seja preciso: definições devem ser claras e corretas


Seja consistente: use os mesmos nomes para conceitos relacionados


Seja realista: não classifique tudo como alta complexidade


Respeite o conteúdo original: não invente conceitos que não estão no livro
