SEÇÃO: CABEÇALHO

Título:

Use o título exato do JSON

Aplicação: Copie do campo "aplicacao_pratica" do JSON

SEÇÃO: DEFINIÇÃO (2-3 frases)

Objetivo:
Apresentar o conceito de forma clara e direta, sem rodeios.

Como escrever:

Primeira frase: Definição técnica do conceito
Segunda frase: Para que serve ou por que é importante
Terceira frase (opcional): Contexto de uso

Exemplo:

## 📌 Definição

Uma variável é um espaço nomeado na memória do computador que armazena um valor. Ela permite que você guarde informações e as reutilize ao longo do programa sem precisar repetir o valor. Variáveis são fundamentais em qualquer programa, pois sem elas seria impossível processar dados ou lembrar informações.

Regras:

Máximo 3 frases
Linguagem simples e direta
Sem introduções longas ("Nesta microaula você aprenderá...")

SEÇÃO: COMPONENTES PRINCIPAIS (2-4 itens)

Objetivo:
Decompor o conceito em suas partes essenciais.

Como escrever:

Liste os componentes do JSON (campo "componentes")
Para cada componente, escreva 1-2 frases de explicação
Use formatação em negrito para o nome do componente

Exemplo:

## 🔍 Componentes Principais

Toda variável possui três características essenciais:

**1. Nome (Identificador)**
É como você se refere à variável no código. Deve ser descritivo e seguir regras da linguagem (não pode começar com número, não pode ter espaços).

**2. Tipo**
Define que tipo de dado a variável pode armazenar: números inteiros (int), decimais (float), texto (string) ou verdadeiro/falso (bool).

**3. Valor**
É o dado atual armazenado na variável. Pode ser modificado ao longo do programa usando o operador de atribuição (=).

Regras:

2-4 componentes apenas (foco!)
1-2 frases por componente
Explicação direta, sem exemplos longos

Objetivo:
Mostrar o conceito em ação com código executável.

Como escrever:

Código: Exemplo simples e funcional (5-10 linhas máximo)

Resultado: Output esperado

Estrutura:

## 💻 Exemplo Prático

Veja como criar e usar uma variável para armazenar e exibir informações:

**Código:**
```python
# Criando variáveis
nome = "Ana"
idade = 28

# Usando as variáveis
print(f"{nome} tem {idade} anos")

Explicação:

Linha 2: Criamos a variável nome e atribuímos o texto "Ana"
Linha 3: Criamos a variável idade e atribuímos o número 28
Linha 6: Usamos as variáveis para exibir uma mensagem formatada

Resultado:

Ana tem 28 anos


**Regras:**
- Apenas 1 exemplo (microaprendizado = foco)
- Código simples (5-10 linhas)
- Comentários no código
- Explicação linha por linha ou bloco por bloco
- Sempre mostre o resultado/output
