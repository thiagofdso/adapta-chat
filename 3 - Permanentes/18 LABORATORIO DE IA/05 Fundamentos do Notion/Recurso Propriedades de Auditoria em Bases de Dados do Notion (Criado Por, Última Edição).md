# Recurso Propriedades de Auditoria em Bases de Dados do Notion (Criado Por, Última Edição)

## 🎯 Categoria
Recurso

## 📌 Sumário Executivo
O Notion oferece propriedades de auditoria como 'Criado por' e 'Última edição' que permitem rastrear a autoria e as modificações de páginas e itens em bases de dados, facilitando a gestão, colaboração e monitoramento de atividades.

## 📝 Descricao
No Notion, as bases de dados permitem a adição de propriedades para enriquecer as informações de cada item. Entre essas propriedades, destacam-se "Criado por" e "Última edição". A propriedade "Criado por" indica o usuário que originalmente criou uma página ou item dentro de uma base de dados. Já a propriedade "Última edição" registra o usuário que realizou a modificação mais recente, bem como a data e hora dessa alteração. Essas são propriedades fundamentais para fins de auditoria e acompanhamento, sendo aplicáveis a qualquer conteúdo em bases de dados, templates ou sistemas dentro do Notion. Elas podem ser visualizadas tanto na exibição geral da base de dados quanto ao abrir os detalhes de um item individualmente. Para otimizar a visualização, é possível ocultá-las se não forem necessárias para o uso cotidiano.

## Complexidade
Iniciante

## ⏱️ Templo de implementação
5-10 min para entender | 15-30 min para aplicar

## ⚡Como Aplicar
1.  Acesse a base de dados no Notion onde você deseja adicionar as propriedades de auditoria.
2.  Se a base de dados estiver bloqueada, desbloqueie-a para permitir edições de propriedades.
3.  Clique em "Adicionar propriedade" (ou "Mais propriedade" se você já tiver muitas propriedades e precisar procurá-las).
4.  Na lista de tipos de propriedade, localize e selecione "Criado por" para rastrear o criador dos itens.
5.  Repita o processo para adicionar a propriedade "Última edição", que registrará quem e quando o item foi modificado pela última vez.
6.  Uma vez adicionadas, essas propriedades serão automaticamente preenchidas para novos itens e exibirão as informações relevantes para itens existentes (se aplicável).
7.  Caso queira uma visualização mais limpa, você pode ocultar essas propriedades clicando sobre elas e selecionando a opção "sempre ocultar".

## �� Exemplos Práticos
*   Em uma base de dados de tarefas de marketing, a propriedade "Criado por" pode indicar quem designou inicialmente uma tarefa, e "Última edição" pode mostrar quem atualizou seu status ou adicionou comentários por último.
*   Em um repositório de documentos, "Criado por" identifica o autor original, e "Última edição" revela o revisor mais recente e a data da revisão.
