# Dica Duplicação de Documentos para Adicionar Novas Entradas no Template Gesto do Notion

## 🎯 Categoria
Tip

## 📌 Sumário Executivo
Para adicionar novos documentos no template Gesto do Notion, que é configurado para documentos existentes, é mais eficaz duplicar um documento existente e editá-lo, em vez de criar um novo do zero.

## 📝 Descricao
No template Gesto do Notion, que foi configurado especificamente para operar com um conjunto predefinido de documentos, não é possível criar novos documentos diretamente, pois eles não apareceriam no sistema. Para incluir um novo documento ou uma nova opção de lista editorial, a solução é duplicar um documento já existente dentro do sistema e então editá-lo com o novo conteúdo. Esta abordagem é necessária devido à configuração específica do template Gesto e é preferível a tentar criar um documento do zero, que não funcionaria. Enquanto documentos são duplicados, tarefas podem ser adicionadas diretamente.

## Complexidade
Iniciante

## ⏱️ Templo de implementação
5-10 min para entender | 10-20 min para aplicar

## ⚡Como Aplicar
1.  Acesse o template Gesto no Notion.
2.  Identifique um documento existente que você deseja usar como base para a nova entrada.
3.  Duplique esse documento.
4.  Edite o documento duplicado com o novo conteúdo ou as novas informações desejadas.
5.  Para tarefas, que possuem um processo diferente, você pode adicioná-las diretamente sem a necessidade de duplicação.

## 💡 Exemplos Práticos
*   Se você deseja adicionar uma nova opção de lista editorial no Gesto, duplique um documento de lista editorial já existente e modifique seu conteúdo.
*   Para criar um novo tipo de documento dentro do escopo já configurado, use um documento similar como modelo, duplique-o e preencha com os detalhes do novo documento.

## ⚠️ Armadilhas Comuns
A principal armadilha é tentar criar um documento novo diretamente no template Gesto sem duplicar um existente. Essa ação fará com que o novo documento não apareça no sistema, pois o template foi configurado para trabalhar apenas com os documentos gerados a partir de um conjunto inicial.

## Consideracoes
Esta técnica é específica para o template Gesto do Notion devido à sua configuração particular. O template foi desenvolvido para funcionar com documentos pré-configurados, e tentar modificar esse fluxo para permitir a criação direta de documentos não é recomendado por não valer a pena, dada a grande quantidade de usuários que já o utilizam e a complexidade de alterar as automações internas.
