# Dica Atalhos para Criação de Blocos no Notion

## 🎯 Categoria
Dica

## 📌 Sumário Executivo
Utilizar atalhos no Notion, como a barra `/` para acessar uma lista completa de blocos (texto, mídia, bases de dados, etc.) e o jogo da velha `#` para formatar títulos, otimiza o processo de criação e edição de conteúdo.

## 📝 Descricao
O Notion oferece atalhos para a criação e inserção rápida de diversos tipos de blocos, agilizando a construção de páginas e sistemas. Ao digitar a barra `/` (barra), o usuário tem acesso a um menu suspenso que exibe todas as opções de blocos disponíveis, incluindo blocos simples, funcionalidades de IA, opções de mídia (imagens, vídeos, áudios), e bases de dados. É possível navegar por esse menu usando o scroll do mouse para selecionar o bloco desejado. Além disso, para a criação de títulos, pode-se usar o atalho `#` (jogo da velha) seguido de um espaço, que automaticamente formata o texto como um título de nível 1. Repetindo o `#` (ex: `##` para título 2, `###` para título 3), é possível criar títulos de diferentes tamanhos, facilitando a estruturação hierárquica do conteúdo.

## Complexidade
Iniciante

## ⏱️ Templo de implementação
1-2 min para entender | 1-5 min para aplicar

## ⚡Como Aplicar
1.  **Para acessar o menu de blocos:** Em qualquer página do Notion, digite `/` (barra). Uma lista de opções de blocos aparecerá.
2.  **Para selecionar um bloco:** Navegue pela lista com as setas do teclado ou scroll do mouse e clique no bloco desejado ou pressione Enter quando a opção estiver destacada.
3.  **Para criar títulos:**
    *   Digite `#` seguido de um espaço para criar um Título 1 (o maior).
    *   Digite `##` seguido de um espaço para criar um Título 2.
    *   Digite `###` seguido de um espaço para criar um Título 3, e assim por diante.

## 💡 Exemplos Práticos
*   Digitar `/` e selecionar "Texto" para adicionar um parágrafo.
*   Digitar `/` e selecionar "Imagem" para incorporar uma imagem.
*   Digitar `/` e selecionar "Base de dados em linha" para criar uma nova base de dados.
*   Digitar `# Minha Página Principal` resultará em um título grande para a página.
*   Digitar `## Seção de Tarefas` criará um subtítulo para organizar as tarefas.
