## 🎯 Categoria
Conceito

## �� Sumário Executivo
As bases de dados no Notion são páginas que operam como "planilhas inteligentes", permitindo a criação de campos personalizáveis, chamados de propriedades, para uma organização e visualização estruturada de informações.

## 📝 Descricao
As bases de dados no Notion são definidas como páginas que funcionam como "planilhas inteligentes". Nestas bases, o usuário tem a capacidade de criar diversos "campos", os quais são designados como "propriedades". Cada propriedade corresponde a uma coluna na base de dados, facilitando a organização e visualização das informações, especialmente em formato de tabela. Para a compreensão da estrutura, cada campo é considerado uma propriedade, e cada página criada dentro de uma base de dados é, por sua vez, vista como um bloco.

## ⚡Como Aplicar
Para criar uma base de dados no Notion, pode-se usar o atalho de barra (/) seguido da seleção de "Base online" e, em seguida, nomear a base. Após a criação, é possível adicionar propriedades, como "seleção" ou "multi-seleção", para categorizar as informações.

## 💡 Exemplos Práticos
Um exemplo prático mencionado é a criação de uma base de dados para "conteúdo" e outra para "clientes". Essas duas bases podem ser relacionadas através de uma propriedade específica, permitindo vincular clientes a conteúdos. Por exemplo, pode-se associar um cliente como "Eduarda Dias" a um "vídeo para Instagram".
