# Técnica Fornecimento Inicial de Dados para IA

## 🎯 Categoria
Técnica

## �� Sumário Executivo
Esta técnica descreve o método inicial de fornecimento de dados para uma Inteligência Artificial (IA), especificamente o GPT, com o objetivo de iniciar o processo de desenvolvimento de uma identidade visual para um projeto. Envolve a alimentação da IA com o DNA do projeto (incluindo os três DNAs) e o manual do tom de voz, que servem como direcionadores fundamentais para que a IA interprete a identidade do projeto e comece a gerar o conceito da marca.

## 📝 Descricao
A técnica de fornecimento inicial de dados para a IA é o ponto de partida para a criação de uma identidade visual usando ferramentas de Inteligência Artificial, como o GPT. Neste módulo, foca-se em como o agente de IA é "iniciado" com as informações cruciais do projeto. Duas informações principais são enviadas para a IA: o DNA do projeto (que abrange os três DNAs) e o manual do tom de voz. O DNA do projeto fornece a essência e os valores fundamentais, enquanto o manual do tom de voz já estabelece as diretrizes de comunicação verbal, incluindo termos recorrentes, proibidos, autorais, expressões, analogias e o tom geral. A IA interpreta essas informações para compreender a identidade do projeto e, com base nessa compreensão, gera o conceito da marca. Este conceito de marca é o primeiro elemento da identidade visual e funciona como um documento matriz, servindo de base para todos os elementos subsequentes da estratégia visual.

## ⏱️ Templo de implementação
10-15 min para entender | 1-2 horas para aplicar

## ⚡Como Aplicar
1.  **Reúna o DNA do Projeto:** Certifique-se de ter os "três DNAs" do seu projeto ou cliente bem definidos e documentados.
2.  **Disponha o Manual do Tom de Voz:** Tenha o manual do tom de voz do projeto pronto, contendo diretrizes verbais como termos recorrentes, proibidos, autorais, expressões, analogias e o tom geral.
3.  **Envie as Informações para a IA:** Apresente essas duas informações (DNA do projeto e manual do tom de voz) ao agente de IA (GPT). Isso pode ser feito através de prompts ou carregamento de documentos, dependendo da interface da ferramenta.
4.  **Aguarde a Interpretação e Geração:** A IA irá interpretar esses dados para compreender a identidade do projeto e, então, gerará o "conceito da marca", que é o ponto de partida para a identidade visual.

## �� Exemplos Práticos
Ao iniciar um novo projeto de branding para uma empresa de tecnologia focada em sustentabilidade, o usuário forneceria à IA:
*   **DNA do projeto:** Um documento detalhando os valores da empresa (inovação, responsabilidade ambiental, comunidade), sua missão e visão.
*   **Manual do tom de voz:** Um guia que especifica que a comunicação deve ser formal, inspiradora, mas acessível, evitando jargões técnicos excessivos e utilizando analogias com a natureza.
A IA, ao receber esses dados, desenvolveria um conceito de marca que reflete esses pilares, como "Tecnologia Verde Conectando Futuros".

## Consideracoes
É crucial que o DNA do projeto e o manual do tom de voz sejam completos e claros, pois a qualidade do "conceito da marca" gerado pela IA dependerá diretamente da riqueza e precisão desses dados iniciais. Essa etapa visa dar um direcionamento sólido à IA, garantindo que a identidade visual desenvolvida esteja alinhada com a essência e os objetivos do projeto.
