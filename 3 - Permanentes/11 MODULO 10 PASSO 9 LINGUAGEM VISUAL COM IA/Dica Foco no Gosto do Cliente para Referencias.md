# Dica Foco no Gosto do Cliente para Referencias

## �� Categoria
Dica

## 📌 Sumário Executivo
Ao enviar referências visuais para a IA, especialmente em projetos para terceiros, é crucial considerar e traduzir o gosto e as preferências do cliente, e não as próprias, para garantir que a identidade visual gerada esteja alinhada às expectativas do cliente.

## �� Descricao
Quando se está fornecendo referências visuais para uma inteligência artificial desenvolver padrões visuais e o manual visual de um projeto, é fundamental que o "gosto" traduzido pela IA seja o do cliente. Se a estratégia for para uso pessoal ou de seu próprio negócio, pode-se usar o próprio gosto. Contudo, se o projeto for para um terceiro (um cliente), é imprescindível que as referências enviadas reflitam o que o cliente gosta e acha interessante, e não as preferências pessoais do consultor ou da pessoa que está alimentando a IA. A IA utilizará esses padrões visuais, unificados com o conceito de marca, para desenvolver o manual visual final.

## Complexidade
Iniciante

## ⏱️ Templo de implementação
5-10 min para entender | 0-1 hora para aplicar

## ⚡Como Aplicar
1.  Ao coletar referências visuais para um projeto de cliente, certifique-se de que as imagens, vídeos e artes selecionadas correspondam ao estilo, estética e preferências expressas ou percebidas do cliente.
2.  Converse com o cliente para entender suas inspirações, o que ele considera interessante e quais marcas ou estilos visuais ele admira ou gostaria de associar ao seu projeto.
3.  Evite impor suas próprias preferências estéticas ao selecionar as referências, a menos que o cliente especificamente peça sua curadoria com base em sua expertise.
4.  Envie essas referências focadas no cliente para a IA, para que o documento de padrões visuais gerado reflita a identidade desejada pelo cliente.

## �� Exemplos Práticos
*   Se um cliente de uma marca de luxo prefere um estilo minimalista e cores sóbrias, todas as referências visuais enviadas para a IA devem seguir essa linha, mesmo que o responsável pelo envio pessoalmente prefira estilos mais vibrantes.
*   Caso um cliente de um novo aplicativo de fitness expresse admiração por marcas com tipografia forte e imagens dinâmicas, as referências devem incluir exemplos que capturem essa energia e estilo.

## ⚠️ Armadilhas Comuns
*   Utilizar suas próprias preferências de estilo em vez das do cliente, resultando em uma identidade visual que não agrada ao cliente ou não se alinha à visão do projeto.
*   Não validar as referências com o cliente antes de enviá-las para a IA, o que pode levar a retrabalho e frustração.
