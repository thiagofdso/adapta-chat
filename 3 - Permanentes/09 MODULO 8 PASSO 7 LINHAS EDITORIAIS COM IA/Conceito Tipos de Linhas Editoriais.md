# Conceito Tipos de Linhas Editoriais

## 🎯 Categoria
Conceito

## 📌 Sumário Executivo
Existem nove tipos de linhas editoriais (técnica, científica, educacional, motivacional, cultural, estilo de vida, entretenimento, tutorial, notícias) usadas para direcionar a criação de conteúdo, sendo o GPT uma ferramenta eficaz para definir quais são as mais pertinentes para um projeto específico.

## 📝 Descricao
As linhas editoriais são categorias que servem para guiar a criação de conteúdo de um projeto. Existem nove tipos de linhas editoriais reconhecidas. O papel do GPT, neste contexto, é analisar o projeto e o seu devido contexto para, em seguida, identificar quais dessas nove linhas editoriais são as mais relevantes e pertinentes para a natureza e estratégia do projeto em questão. As linhas editoriais escolhidas formarão a base para todas as ideias de conteúdo subsequentes que o GPT irá propor, garantindo que o conteúdo esteja alinhado com os objetivos do projeto. A quantidade de linhas editoriais definidas pode variar, sendo por vezes todas as nove, ou apenas duas ou três, dependendo da especificidade do projeto.
