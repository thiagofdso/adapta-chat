# Recurso Integração de Mapas Mentais para Linhas Editoriais no Mapa de Conteúdo

## 🎯 Categoria
Recurso

## 📌 Sumário Executivo
Capacidade do mapa de conteúdo de integrar e exibir links ou imagens de mapas mentais para organizar e centralizar as linhas editoriais que foram elaboradas externamente.

## 📝 Descricao
O mapa de conteúdo oferece uma funcionalidade que permite a integração de linhas editoriais elaboradas por meio de mapas mentais externos. Se o usuário preferir definir suas linhas editoriais utilizando um mapa mental em vez de preenchê-las diretamente na ferramenta, é possível acessar uma seção de descrição específica. Nesta seção, o usuário pode clicar para indicar que utiliza mapas mentais para elaborar suas linhas editoriais e, em seguida, inserir o link para o mapa mental. Além da inserção do link, o recurso permite que sejam adicionadas imagens, seja do próprio mapa mental ou de uma foto do mapa de linhas editoriais, diretamente no mapa de conteúdo. Essa capacidade assegura que toda a organização das linhas editoriais fique centralizada e encadeada dentro do mapa de conteúdo, evitando a dispersão das informações em múltiplos locais.

## Complexidade
Iniciante

## ⏱️ Templo de implementação
5-10 min para entender | 0.5-1 hora para aplicar

## ⚡Como Aplicar
1.  No mapa de conteúdo, navegue até a área onde as linhas editoriais são definidas, que pode estar na aba de pesquisa estratégica.
2.  Localize a opção ou descrição que permite a integração de mapas mentais externos, geralmente indicada por uma frase como "Se você utiliza mapas mentais para elaborar suas linhas editoriais, clica aqui".
3.  Ao clicar nesta opção, você poderá inserir o link do seu mapa mental.
4.  Opcionalmente, adicione imagens do seu mapa mental ou de uma foto do seu mapa de linhas editoriais para uma visualização mais completa dentro do mapa de conteúdo.
5.  Certifique-se de salvar as alterações após adicionar o link ou as imagens.

## 🔧 Ferramentas Necessarias

## Consideracoes
Este recurso é ideal para usuários que já possuem um fluxo de trabalho estabelecido com mapas mentais para a criação de suas linhas editoriais e desejam manter essa metodologia, ao mesmo tempo em que centralizam todas as referências dentro do mapa de conteúdo. Permite uma organização eficiente e integrada, conectando ferramentas diferentes.
