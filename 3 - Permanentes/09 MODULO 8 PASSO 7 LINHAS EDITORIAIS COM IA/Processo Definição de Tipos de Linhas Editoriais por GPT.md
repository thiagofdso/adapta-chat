# Processo Definição de Tipos de Linhas Editoriais por GPT

## 🎯 Categoria
Processo

## �� Sumário Executivo
Este processo descreve como um GPT customizado, após analisar os documentos e o contexto de um projeto, define os tipos de linhas editoriais mais pertinentes para a estratégia do projeto. Ele seleciona entre nove tipos existentes para guiar as etapas subsequentes de brainstorm.

## 📝 Descricao
O processo de definição dos tipos de linhas editoriais por GPT inicia com o envio e processamento de documentos do projeto para o GPT customizado, que é o GPT principal de linhas editoriais. Este GPT tem a função de analisar o projeto e entender seu contexto com base nas informações fornecidas. A partir dessa análise, o GPT define quais dos nove tipos de linhas editoriais existentes são mais relevantes e fazem sentido para o projeto em questão. Essa definição é a primeira etapa do uso do GPT na curadoria de linhas editoriais e serve como base para todas as ideias de linhas editoriais que serão propostas posteriormente, garantindo que estejam alinhadas aos formatos identificados como adequados para o projeto. O número de tipos de linhas editoriais propostos pelo GPT pode variar, podendo ser apenas dois ou três, ou até mesmo todos os nove, dependendo da natureza e complexidade do projeto. Após essa definição inicial, a validação do usuário é crucial para aprovar os tipos sugeridos e permitir que o GPT prossiga para a fase de brainstorm.

## Complexidade
Intermediario

## ⏱️ Templo de implementação
15-20 min para entender | 1-2 horas para aplicar

## ⚡Como Aplicar
1.  **Envio de Documentos:** Alimente o GPT customizado com os documentos do projeto, que contenham informações estratégicas e de contexto.
2.  **Análise do Projeto:** Permita que o GPT processe e analise os documentos, compreendendo o contexto e os objetivos do projeto.
3.  **Definição dos Tipos:** O GPT definirá e apresentará os tipos de linhas editoriais que considera mais pertinentes para a estratégia do projeto, selecionando entre as nove categorias existentes.
4.  **Validação:** Revise os tipos de linhas editoriais propostos pelo GPT e valide se eles fazem sentido para o projeto. Em caso de aprovação, conceda permissão para que o GPT avance para a próxima etapa de brainstorm.

## 💡 Exemplos Práticos
O GPT pode identificar que, para um projeto focado em educação financeira, os tipos de linhas editoriais mais pertinentes seriam:
*   Linha editorial técnica
*   Linha editorial científica
*   Linha editorial educacional
*   Linha editorial motivacional
*   Linha editorial de notícias
Um projeto de viagens, por outro lado, poderia ter como pertinentes:
*   Linha editorial cultural
*   Linha editorial de estilo de vida
*   Linha editorial de entretenimento
*   Linha editorial de tutorial

Os nove tipos de linhas editoriais que o GPT pode considerar são: técnica, científica, educacional, motivacional, cultural, estilo de vida, entretenimento, tutorial e notícias.

## 📊 Metricas/Resultados
O principal resultado deste processo é a definição clara e validada dos tipos de linhas editoriais que nortearão toda a estratégia de conteúdo do projeto. Este output serve como um pilar fundamental para o brainstorm e o desenvolvimento de ideias mais específicas de conteúdo.

## 🔧 Ferramentas Necessarias
*   GPT customizado (GPT principal de linhas editoriais)

## Consideracoes
A acurácia da definição dos tipos de linhas editoriais depende diretamente da qualidade e completude dos documentos e informações fornecidas ao GPT. O resultado pode variar de dois ou três tipos até a sugestão de todos os nove, de acordo com a amplitude do projeto. A validação humana após a proposta do GPT é uma etapa crítica para assegurar o alinhamento com a estratégia do projeto.
