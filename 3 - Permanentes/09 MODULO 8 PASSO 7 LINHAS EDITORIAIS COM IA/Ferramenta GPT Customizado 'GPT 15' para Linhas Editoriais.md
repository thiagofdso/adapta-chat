## 📌 Sumário Executivo
O GPT 15 é um agente customizado especializado em estratégia editorial para projetos digitais, projetado para definir linhas editoriais que efetivamente conectam persona e produto, reforçam o posicionamento da marca e impulsionam a conversão. Sua funcionalidade envolve a ingestão gradual de diversos documentos do projeto, como objetivos, DNAs, jornada de compra e perfil de persona, para construir uma compreensão aprofundada antes de realizar brainstorms e propor linhas editoriais detalhadas.

## 📝 Descricao
O "GPT 15", ou "GPT de linhas editoriais", é um agente customizado desenvolvido para atuar como um especialista em estratégia editorial para o contexto de projetos digitais. Sua principal função é definir linhas editoriais que sejam altamente alinhadas com os objetivos do projeto, garantindo uma conexão eficaz entre a persona-alvo e o produto/serviço oferecido. Este GPT visa não apenas solidificar o posicionamento da marca no mercado, mas também impulsionar as taxas de conversão através de uma estratégia de conteúdo bem fundamentada.

A ferramenta é caracterizada por um rigor metodológico, o que significa que ela segue um processo estruturado e detalhado para gerar as linhas editoriais. Este processo inclui uma análise documental exaustiva de todos os inputs fornecidos e uma validação contínua em cada fase, assegurando que as sugestões sejam pertinentes e de alta qualidade.

O funcionamento do GPT 15 envolve a submissão de informações de forma faseada. Inicialmente, o GPT recebe documentos base para que possa compreender o projeto em sua totalidade. Esses documentos incluem: os objetivos do projeto, os três DNAs (provavelmente diferenciais ou identidades), a jornada de compra do cliente e o perfil de persona detalhado. Esta primeira fase é crucial para que a IA forme uma base sólida de entendimento sobre o cenário e o público-alvo.

Após esta compreensão inicial, o GPT avança para etapas mais específicas, como os brainstorms de linhas editoriais. Para estas etapas, ele solicita documentos adicionais, como a análise de conteúdos virais previamente realizada, palavras-chave relevantes para o projeto e termos específicos do projeto. O envio desses documentos ocorre em momentos distintos, não todos de uma vez, para otimizar o processamento e a capacidade da IA de executar métodos específicos de brainstorm e de definição de linha editorial.

O GPT 15 não apenas gera as linhas editoriais, mas também propõe tipos de linhas editoriais consideradas mais pertinentes para o projeto (como educacional, técnica, motivacional, tutorial, estilo de vida, científica), e realiza brainstorms com base nos documentos de entrada. Ele é interativo, solicitando a permissão do usuário para avançar e permitindo que o usuário faça curadorias ativas, indicando linhas editoriais obrigatórias e solicitando alterações em descrições ou frequências de publicação por canal. Ao final, ele detalha os assuntos e temas de cada linha editorial, criando uma estrutura rica para a produção de conteúdo.
