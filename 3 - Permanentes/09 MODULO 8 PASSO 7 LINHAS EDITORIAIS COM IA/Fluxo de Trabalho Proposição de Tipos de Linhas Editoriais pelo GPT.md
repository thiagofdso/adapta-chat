# Fluxo de Trabalho Proposição de Tipos de Linhas Editoriais pelo GPT

## 🎯 Categoria
Processo

## 📌 Sumário Executivo
Após a síntese dos documentos base do projeto, o GPT propõe tipos de linhas editoriais mais pertinentes (ex: Educacional, Técnica, Motivacional, Tutorial, Estilo de Vida, Científica), levando em consideração os objetivos estratégicos, DNA, persona e jornada de compra, antes de avançar para o brainstorm de ideias.

## 📝 Descricao
O fluxo de trabalho para a proposição de tipos de linhas editoriais pelo GPT inicia-se após o envio e processamento dos documentos base do projeto, que incluem os objetivos do projeto, os três DNAs, a jornada de compra e o perfil de persona. O GPT, que é o "GPT 15" customizado e especialista em estratégia editorial para projetos digitais, processa essas informações para entender o projeto.

Após essa fase de compreensão e síntese dos dados, o GPT sugere os tipos de linhas editoriais que considera mais adequados e pertinentes para o projeto. Essa sugestão é fundamentada na análise dos objetivos estratégicos, do DNA do projeto, do perfil da persona e da jornada de compra. A proposta visa reforçar o posicionamento, conectar a persona ao produto e impulsionar a conversão. Este passo é considerado intermediário e estratégico para que o GPT desenvolva uma compreensão gradual do projeto, culminando em respostas mais qualificadas e um brainstorm mais eficaz.

Os tipos de linhas editoriais propostos pelo GPT são acompanhados de justificativas que explicam a sua relevância para o público-alvo e para os objetivos do projeto. Exemplos de linhas propostas incluem:
*   **Educacional**: Para que as personas compreendam o modelo de construção para venda.
*   **Técnica**: Direcionada a profissionais e investidores que valorizam profundidade e racionalidade.
*   **Motivacional**: Com o objetivo de quebrar objeções emocionais e inspirar ação.
*   **Tutorial**: Focada em demonstrar o "como fazer" através de passo a passo e simulações.
*   **Estilo de Vida**: Para humanizar o projeto, mostrando rotinas e bastidores reais.
*   **Científica**: Para perfis que buscam lógica, dados e Retorno sobre Investimento (ROI).

O usuário tem a oportunidade de validar e permitir que o GPT avance para a próxima etapa do processo.

## Complexidade
Intermediario

## ⏱️ Templo de implementação
5-10 min para entender | 15-30 min para aplicar

## ⚡Como Aplicar
1.  **Acessar o GPT Customizado**: Abra o "GPT 15", o agente customizado especializado em estratégia editorial para projetos digitais.
2.  **Enviar Documentos Base**: Forneça ao GPT os seguintes documentos iniciais:
    *   Objetivos do projeto
    *   Os três DNAs do projeto
    *   A jornada de compra
    *   O perfil de persona
    Envie esses documentos gradualmente, priorizando os base para que o GPT possa entender o contexto geral do projeto.
3.  **Aguardar Processamento e Síntese**: O GPT irá processar as informações dos documentos base e gerar uma síntese para confirmar sua compreensão do projeto.
4.  **Revisar Proposta de Linhas Editoriais**: O GPT apresentará uma lista de tipos de linhas editoriais que ele considera pertinentes para o projeto, acompanhadas de suas respectivas justificativas.
5.  **Permitir Avanço**: Após revisar a proposta, confirme ao GPT que ele pode avançar para a próxima etapa (brainstorm).

## Consideracoes
*   É crucial enviar os documentos base (objetivos, DNAs, jornada de compra, perfil de persona) primeiro, em momentos distintos dos documentos mais específicos, para que o GPT construa uma compreensão sólida do projeto.
*   Esta etapa é intermediária e serve para criar "momentum" no GPT, permitindo que ele gere respostas de melhor qualidade nas fases posteriores.
*   O output desta fase (os tipos de linhas editoriais propostos) pode ser salvo, mas não é estritamente necessário, pois o interesse principal são as respostas subsequentes do GPT.
