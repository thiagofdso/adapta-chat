# Técnica Análise de Conteúdos Virais (Deep Research)

## 🎯 Categoria
Técnica

## �� Sumário Executivo
Esta técnica envolve o uso de um GPT intermediário, conhecido como Deep Research, para analisar links de conteúdos virais de concorrentes e do próprio cliente. O objetivo é identificar padrões de sucesso, falhas e "alavancas exponenciais" que influenciam o desempenho de conteúdos, criando assim uma "fórmula dos conteúdos virais". Os insights gerados são posteriormente utilizados para propor ideias de linhas editoriais eficazes e alinhadas ao projeto.

## �� Descricao
A Técnica de Análise de Conteúdos Virais, ou Deep Research, é uma etapa crucial no processo de definição de linhas editoriais, utilizando um GPT intermediário para coletar e processar informações sobre o cenário de conteúdo existente. Este GPT não é um agente customizado, mas uma funcionalidade dentro do próprio chat, operando com um prompt específico para a análise de conteúdos virais.

O processo inicia-se com a inserção de links de conteúdos virais relevantes do mercado, abrangendo tanto concorrentes quanto o próprio cliente. Estes links são provenientes de uma curadoria prévia, onde foram selecionados os principais conteúdos para a coleta de relatos de campo.

Após receber os links, o GPT de Deep Research realiza uma análise aprofundada desses materiais. O propósito central é identificar padrões de sucesso (o que funciona) e padrões de falha (o que não funciona) nos conteúdos analisados. Ele busca desvendar as "alavancas exponenciais", que são os elementos-chave responsáveis pelo alto desempenho de certos conteúdos.

O resultado dessa análise é a criação de uma "fórmula dos conteúdos virais" específica para o nicho ou mercado em questão, baseada nos padrões observados nos concorrentes. O GPT gera um relatório ou uma análise detalhada, destacando todos os pontos identificados como alavancas exponenciais que fizeram os conteúdos performar bem ou não.

Essa análise estruturada é então inserida como um input para o GPT principal de definição de linhas editoriais. Com base nos insights sobre o tipo de conteúdo e os padrões de performance do mercado, o GPT principal é capaz de propor ideias de linhas editoriais que são mais embasadas e têm maior probabilidade de sucesso, pois consideram o que já se provou viral e eficaz. A análise dos conteúdos virais é um dos três métodos usados para o brainstorm de linhas editoriais, complementando a análise por persona/jornada de compra e por palavras-chave.

## ⚡Como Aplicar
1.  **Curadoria de Conteúdos Virais**: Selecione e organize os links de conteúdos virais do mercado, incluindo os de concorrentes e do próprio cliente, que foram identificados como relevantes na fase de coleta de relatos de campo.
2.  **Utilização do Deep Research (GPT Intermediário)**: Acesse o GPT intermediário (via prompt no chat) e insira todos os links curados.
3.  **Análise de Padrões**: Permita que o GPT analise os conteúdos para identificar padrões de sucesso e falha, bem como as "alavancas exponenciais" que impulsionam o engajamento e a viralidade.
4.  **Geração da Análise**: O GPT produzirá uma análise detalhada, que pode ser interpretada como a "fórmula dos conteúdos virais" para aquele nicho. Esta análise conterá os pontos cruciais que fazem um conteúdo ter bom desempenho.
5.  **Input para o GPT Principal de Linhas Editoriais**: Insira a análise gerada pelo Deep Research no GPT principal responsável pela definição das linhas editoriais.
6.  **Proposição de Linhas Editoriais**: Com base nesta análise e nos padrões de conteúdo viral identificados, o GPT principal irá propor ideias de linhas editoriais mais assertivas e com maior potencial de ressonância com o público.

## 📊 Metricas/Resultados
*   Identificação clara de padrões de conteúdo que geram alta performance ("coisas que funcionam").
*   Identificação de padrões de conteúdo que não geram boa performance ("coisas que não funcionam").
*   Descoberta de "alavancas exponenciais" que impulsionam a viralidade e o engajamento.
*   Criação de uma "fórmula dos conteúdos virais" baseada na análise de concorrentes.
*   Proposição de ideias de linhas editoriais mais eficazes e com maior probabilidade de atingir os objetivos do projeto, devido ao embasamento em dados de performance real do mercado.

## Consideracoes
A análise dos conteúdos virais pode ser realizada em diferentes momentos do fluxo de trabalho: tanto antes de iniciar a definição das linhas editoriais, quanto de forma mais integrada, onde a análise é feita e o resultado é imediatamente incorporado ao processo de brainstorm. É um dos últimos documentos a serem gerados antes da definição final das linhas editoriais.
