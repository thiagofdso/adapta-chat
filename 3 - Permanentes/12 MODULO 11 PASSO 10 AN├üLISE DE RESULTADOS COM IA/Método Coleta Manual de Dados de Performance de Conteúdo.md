# Método Coleta Manual de Dados de Performance de Conteúdo

## 🎯 Categoria
Método

## 📌 Sumário Executivo
Abordagem para extrair métricas de forma individualizada, acessando os insights ou analytics de cada publicação e registrando-as, ideal para conjuntos menores de dados ou análises pontuais.

## 📝 Descricao
A extração manual é a primeira forma de coletar dados de conteúdo. Ela consiste em abrir os insights ou a seção de analíticos de uma publicação específica no canal digital que está sendo analisado (por exemplo, insights do Instagram ou YouTube Analytics). O usuário deve visualizar individualmente a métrica de cada post e anotá-la em uma planilha. Este método é considerado o mais fácil, mas torna-se trabalhoso e difícil se a análise abranger um período muito grande, como os conteúdos dos últimos seis meses. É recomendado para análises menores, como a de 10 vídeos ou posts dos últimos 7 dias. Pode-se adotar como rotina semanal anotar os dados dos posts publicados para compilar uma análise mensal.

## Complexidade
Iniciante

## ⏱️ Templo de implementação
10-20 min para entender | 1-2 horas para aplicar

## ⚡Como Aplicar
1.  Acesse a ferramenta de insights ou analytics da plataforma digital para a publicação desejada.
2.  Visualize as métricas individualmente para cada post ou conteúdo.
3.  Anote as métricas relevantes em uma planilha.
4.  Para análises mensais, estabeleça uma rotina semanal de coleta dos dados dos posts publicados, consolidando-os ao final do mês.

## �� Exemplos Práticos
*   Analisar manualmente as métricas de 10 vídeos selecionados em um canal do YouTube.
*   Coletar os dados de performance de todos os posts de uma semana específica no Instagram, anotando-os em uma planilha.
*   Manter um registro semanal das métricas dos conteúdos para preparar uma análise mensal consolidada no final do mês.

## ⚠️ Armadilhas Comuns
*   Torna-se inviável e trabalhoso para analisar grandes volumes de conteúdo ou períodos extensos (ex: últimos seis meses), devido à natureza manual da coleta.

## 🔧 Ferramentas Necessarias
*   Ferramentas de insights ou analytics nativas das plataformas digitais (ex: YouTube Analytics, Instagram Insights).
*   Planilha (para registro e organização dos dados).

## Consideracoes
Este método é o mais simples e acessível, sendo ideal para iniciantes ou para a análise de um número limitado de conteúdos. A sua eficiência diminui consideravelmente com o aumento do volume de dados a serem coletados.
