# Processo Passo 9 - Linguagem Visual

## 🎯 Categoria
Processo

## 📌 Sumário Executivo
O nono passo da estratégia de conteúdo com inteligência artificial é dedicado à definição da linguagem visual do projeto. Este processo utiliza um agente de IA específico (GPT9) para complementar a linguagem falada, já estabelecida no [[Processo Passo 2 - Definir DNA do Projeto e Conteúdo]], resultando na linguagem completa da marca ou projeto.

## 📝 Descricao
O nono passo do método de estratégia de conteúdo com IA foca na definição da linguagem visual. Esta etapa é crucial pois complementa a linguagem falada, que foi previamente estabelecida no módulo de estratégia, mais especificamente no [[Processo Passo 2 - Definir DNA do Projeto e Conteúdo]], onde o tom de voz é definido. A finalidade é criar uma "linguagem" completa para o projeto, que inclui tanto os aspectos falados quanto os visuais.
Para realizar este passo, é utilizado um agente de inteligência artificial específico, identificado como "GPT9". Este agente é alimentado com informações já geradas ao longo da estratégia de conteúdo. Com base nesses inputs, o agente de IA processa e define a linguagem visual adequada para o projeto. O resultado da união da linguagem visual definida neste passo com a linguagem falada (tom de voz) é a linguagem unificada e completa do projeto.

## Complexidade
Intermediario

## ⏱️ Templo de implementação
10-20 min para entender | 1-2 horas para aplicar

## ⚡Como Aplicar
1.  **Garantir a Definição da Linguagem Falada**: Certifique-se de que a linguagem falada, incluindo o tom de voz, já foi definida no [[Processo Passo 2 - Definir DNA do Projeto e Conteúdo]]. Essa informação será um input crucial para este passo.
2.  **Utilizar o Agente de IA (GPT9)**: Acesse o agente de IA específico destinado à definição da linguagem visual (referido como GPT9).
3.  **Munir o Agente com Informações da Estratégia**: Forneça ao agente as informações relevantes e já consolidadas da sua estratégia de conteúdo. Este agente é descrito como "bem simples" de usar, o que sugere um processo de alimentação de dados direto e eficiente.
4.  **Definição da Linguagem Visual**: O agente processará as informações e definirá os elementos da linguagem visual.
5.  **Unificar as Linguagens**: A linguagem visual definida será então unida à linguagem falada previamente estabelecida, formando a linguagem completa e coesa do projeto.
