# Dica Cuidado ao Editar Banco de Dados do GEST

## 🎯 Categoria
Tip

## 📌 Sumário Executivo
Advertência importante no GEST sobre a edição do banco de dados central do Notion, que sustenta todo o template, recomendando não alterá-lo sem conhecimento aprofundado.

## 📝 Descricao
Dentro da ferramenta GEST, na seção da "central", que corresponde ao banco de dados principal do sistema, há uma forte recomendação para que os usuários evitem modificar este banco de dados. A ressalva é feita para aqueles que não possuem um conhecimento aprofundado tanto do próprio sistema GEST quanto da plataforma Notion, pois este banco de dados é o fundamento que sustenta a funcionalidade de todo o template.
