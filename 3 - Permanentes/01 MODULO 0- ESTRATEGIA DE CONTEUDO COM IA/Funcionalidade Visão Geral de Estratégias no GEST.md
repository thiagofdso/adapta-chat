# Funcionalidade Visão Geral de Estratégias no GEST

## 🎯 Categoria
Funcionalidade

## 📌 Sumário Executivo
A Visão Geral de Estratégias no GEST é a aba inicial da ferramenta onde o usuário pode encontrar um panorama completo das estratégias de conteúdo em que está trabalhando, incluindo as ativas, um Kanban de acompanhamento de status, um calendário mensal e uma linha do tempo das estratégias.

## �� Descricao
Ao acessar a ferramenta GEST no Notion, o usuário é direcionado à aba inicial, convenientemente nomeada "estratégias". Esta seção serve como um hub centralizado, oferecendo uma visão panorâmica e consolidada de todas as estratégias de conteúdo em desenvolvimento. Dentro desta funcionalidade, o usuário encontrará:
*   **Estratégias Ativas**: Uma lista clara das estratégias que estão atualmente em produção, indicando quais projetos demandam atenção imediata.
*   **Kanban de Estratégias**: Um quadro visual que permite acompanhar os principais estágios de cada estratégia. Este Kanban inclui fases como "Em espera" (estratégias aguardando início), "Briefing" (fase inicial com o cliente, aplicável a quem comercializa o serviço), "Execução" (estratégias em criação), "Revisão" (processo final de verificação), "Entrega" (apresentação ao cliente) e "Finalizado" (estratégia entregue). Para uso pessoal, as etapas de "Em espera", "Execução" e "Finalizado" são os guias principais, com "Revisão" sendo indispensável para garantir a qualidade, independentemente do uso comercial.
*   **Calendário**: Uma visão mensal que exibe as datas de entrega de todas as estratégias, proporcionando um cronograma claro e facilitando o gerenciamento de múltiplos projetos.
*   **Timeline**: Uma representação em linha do tempo que permite definir e visualizar as datas de início e término de cada estratégia, oferecendo uma perspectiva temporal do planejamento.

Esta visão inicial é particularmente valiosa para profissionais que gerenciam diversas estratégias simultaneamente, como agências de marketing ou consultores de conteúdo. Contudo, ela também se mostra extremamente útil para quem desenvolve estratégias para seus próprios negócios, bastando ignorar as funções específicas voltadas para a comercialização do serviço.

## ⚡Como Aplicar
1.  **Acessar o GEST**: Abra o template GEST no Notion.
2.  **Navegar para a Visão Geral**: No menu lateral, clique na opção "GEST" para acessar a aba inicial, onde a "visão geral das estratégias" está localizada.
3.  **Analisar as Estratégias Ativas**: Verifique quais estratégias estão listadas como "ativas", indicando que estão em andamento.
4.  **Utilizar o Kanban**: Consulte o quadro Kanban para entender o status de cada estratégia (Em espera, Briefing, Execução, Revisão, Entrega, Finalizado) e identificar rapidamente as próximas ações necessárias.
5.  **Consultar o Calendário**: Observe a visão de calendário para ter uma perspectiva mensal das datas de entrega das diversas estratégias, facilitando o planejamento de prazos.
6.  **Visualizar a Timeline**: Utilize a linha do tempo para acompanhar as datas de início e término de cada estratégia, oferecendo uma compreensão clara do ciclo de vida dos projetos.

## �� Exemplos Práticos
*   **Gerenciamento de Portfólio de Clientes**: Um consultor de marketing pode usar essa funcionalidade para ter uma visão consolidada de todas as estratégias de conteúdo que estão sendo desenvolvidas para diferentes clientes, sabendo rapidamente o status de cada uma e suas próximas entregas.
*   **Planejamento de Lançamentos de Produto**: Uma equipe de marketing de produto pode monitorar as estratégias de conteúdo de diferentes lançamentos, garantindo que os materiais de marketing estejam alinhados com os prazos de lançamento.
*   **Acompanhamento de Projetos Pessoais**: Um empreendedor com múltiplos projetos pessoais pode usar a visão geral para controlar o andamento das estratégias de conteúdo para cada um de seus negócios, priorizando tarefas e alocando recursos de forma eficiente.
