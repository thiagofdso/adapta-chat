## 📌 Sumário Executivo
A funcionalidade Timeline de Estratégias no GEST oferece uma visão de linha do tempo para o planejamento e acompanhamento das datas de início e término de cada estratégia de conteúdo, sendo particularmente útil para quem gerencia múltiplas estratégias simultaneamente.

## 📝 Descricao
A seção "timeline" no GEST proporciona uma visualização da linha do tempo das estratégias de conteúdo. Ela permite ao usuário definir e acompanhar as datas de início e término para cada estratégia. Essa funcionalidade é descrita como uma "visão de linha do tempo da estratégia" e é enfatizada como um recurso valioso para quem está envolvido no gerenciamento de múltiplas estratégias.

Dentro da página detalhada de uma estratégia específica, o GEST apresenta um "timeline das minhas estratégias" que exibe o que está programado, incluindo entregas de estratégias para a semana atual e para o mês. As propriedades como a data de início e a data de término são utilizadas para formar essa timeline e também contribuem para o cálculo do progresso da estratégia, indicando a porcentagem de tarefas completas em relação ao total.

## Complexidade
Iniciante

## ⏱️ Templo de implementação
5-10 min para entender | 0-1 horas para aplicar

## ⚡Como Aplicar
1.  Acessar a seção "timeline" na interface principal do GEST.
2.  Para uma nova estratégia ou uma existente, localizar os campos para definir a "data de início" e a "data de término".
3.  Preencher essas datas de acordo com o planejamento da estratégia.
4.  Utilizar a visualização de linha do tempo para monitorar o andamento da estratégia e as datas programadas.

## 💡 Exemplos Práticos
*   Para uma nova estratégia de conteúdo, pode-se definir a data de início para uma sexta-feira e a data de término para a segunda-feira seguinte do dia 19, visualizando o período de trabalho na linha do tempo.
*   Ao criar uma nova página de estratégia, é possível configurar suas propriedades para que ela comece em uma determinada sexta-feira e finalize duas sextas-feiras depois, estabelecendo um período de três semanas para a execução da estratégia.

## Consideracoes
Esta funcionalidade é particularmente vantajosa para quem precisa gerenciar diversas estratégias de conteúdo simultaneamente, pois fornece uma visão clara e organizada dos cronogramas. Para usuários que trabalham com uma única estratégia, a visão geral de estratégias ativas pode ser suficiente, mas a timeline ainda oferece um controle visual aprofundado do tempo.
