# Processo Quatro Momentos - Criação de Inputs

## 📝 Descricao
A criação de inputs é o primeiro dos quatro momentos do método de estratégia de conteúdo com inteligência artificial. Este momento envolve a geração e organização de informações e documentos que atuarão como dados de entrada para as IAs. O objetivo é fornecer à IA o contexto necessário para que ela possa processar e gerar outputs relevantes. A criação desses inputs pode ser realizada de duas formas:
*   **Com IA:** A inteligência artificial é utilizada para gerar documentos intermediários. Estes documentos são criados especificamente para serem usados como inputs em outras IAs, e não necessariamente farão parte da estratégia final. Um exemplo citado é a criação de documentos necessários para uma pesquisa de concorrência bem-sucedida. Após o uso, esses documentos intermediários podem ser descartados.
*   **Manualmente:** Alguns inputs precisam ser gerados de forma manual, onde o usuário cria as informações diretamente.
A essência é que os inputs são informações intermediárias ou de contexto que permitem à IA trabalhar de forma eficaz e gerar resultados de alta qualidade.

## Complexidade
Iniciante

## ⏱️ Templo de implementação
15-30 min para entender | 1-2 horas para aplicar

## ⚡Como Aplicar
1.  Identificar as informações necessárias como entradas para as IAs nos próximos passos da estratégia.
2.  Gerar documentos intermediários usando a própria IA, quando aplicável (ex: documentos para pesquisa de concorrência).
3.  Criar manualmente os inputs que exigem conhecimento específico ou dados que a IA não pode gerar por si só.
4.  Organizar esses documentos e informações para que estejam prontos para serem inseridos nos agentes de IA correspondentes.

## 💡 Exemplos Práticos
*   Criação de documentos específicos que detalham o perfil de um projeto para que a IA possa realizar uma análise de concorrência.
*   Geração manual de briefings ou informações detalhadas sobre o cliente que serão usadas como input para a IA definir objetivos.

## Consideracoes
Este momento é crucial para garantir a qualidade dos outputs subsequentes da IA. A premissa de que "quanto melhor o input, melhor o output" é fundamental aqui. Os inputs criados podem ser intermediários e descartáveis após o uso pela IA para gerar um output específico.
