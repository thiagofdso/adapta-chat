# Metodo Coleta de Informações para DNA

## 🎯 Categoria
Metodo

## 📌 Sumário Executivo
Este conhecimento se refere ao processo de coletar o DNA do especialista e o DNA da empresa de forma organizada. É apresentado como um passo crucial que será detalhado em aulas futuras, servindo como input fundamental para o GPT gerar o DNA do conteúdo.

## 📝 Descricao
A coleta de informações para o DNA refere-se à etapa em que se reúnem os dados necessários sobre o especialista e a empresa, que servirão como base para o funcionamento do GPT no processo de criação do DNA do conteúdo. O documento informa que "na próxima aula eu vou mostrar para vocês como que vocês vão coletar, seja do cliente de vocês ou de vocês mesmos, o DNA do especialista e o DNA da empresa". É explicitado que este é o trabalho central desse GPT: "Tu dá o objetivo, dá o DNA do especialista, dá o DNA da empresa, em forma de resposta para perguntas, e ele gera o DNA do conteúdo." A coleta é o que alimenta o sistema com o "DNA do especialista" e o "DNA da empresa", que são formalizados através das respostas fornecidas. A próxima aula abordará os "métodos de coleta de informação do DNA de especialista e do DNA da empresa" de forma bem organizada.
