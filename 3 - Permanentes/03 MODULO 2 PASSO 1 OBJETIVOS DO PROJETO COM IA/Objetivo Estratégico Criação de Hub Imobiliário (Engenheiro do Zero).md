# Objetivo Estratégico Criação de Hub Imobiliário (Engenheiro do Zero)

## 🎯 Categoria
Estrategia

## 📌 Sumário Executivo
O objetivo principal de longo prazo para o projeto Engenheiro do Zero é transformá-lo em um hub imobiliário abrangente. Isso envolve expandir e, eventualmente, descentralizar a imagem do especialista Rafael Weiner para estabelecer uma escola de negócios imobiliários com múltiplos especialistas. O foco é gerar e movimentar negócios imobiliários, como captação de recursos, criação de fundos de investimento e incorporação de empreendimentos, condicionando a mobilização de energia para tal à meta de R$10 milhões de faturamento anual.

## 📝 Descricao
O projeto Engenheiro do Zero tem como um de seus principais objetivos estratégicos a criação de um hub imobiliário. Este objetivo visa expandir o escopo do projeto além da figura central de Rafael Weiner, estabelecendo uma escola de negócios imobiliários que conte com a participação de outros especialistas. O propósito final é que o Engenheiro do Zero se torne um centro gerador de negócios imobiliários, englobando desde a captação de recursos para construção e fundos de investimento imobiliário, até a incorporação de grandes empreendimentos como prédios e shoppings. A ideia é que a base do funil de conversão leve os clientes a investirem e construírem em parceria com a equipe do projeto, efetivamente "girando" negócios imobiliários. A mobilização de energia e recursos para concretizar este ambicioso objetivo está diretamente atrelada ao atingimento de uma meta financeira de R$ 10 milhões de faturamento anual para o projeto.
