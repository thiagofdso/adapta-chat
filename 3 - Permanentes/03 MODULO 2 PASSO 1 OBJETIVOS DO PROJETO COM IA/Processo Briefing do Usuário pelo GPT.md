# Processo Briefing do Usuário pelo GPT

## 🎯 Categoria
Processo

## 📌 Sumário Executivo
Etapa onde o GPT, na ausência ou insuficiência de um diagnóstico inicial, realiza um questionário com o usuário para coletar informações cruciais e compreender o contexto do projeto digital, garantindo que haja dados suficientes para a definição de objetivos.

## 📝 Descricao
Este processo é ativado pelo GPT quando não há um diagnóstico inicial dos canais do cliente disponível, ou quando o diagnóstico existente não fornece dados suficientes para que o GPT compreenda o contexto do projeto. Nele, o GPT inicia um briefing com o usuário, fazendo perguntas centrais para entender a natureza do projeto digital e coletar informações essenciais. O objetivo é assegurar que o GPT possua insumos suficientes para situar o projeto e prosseguir com as etapas de investigação e definição de objetivos.

## Complexidade
Intermediario

## ⏱️ Templo de implementação
10-15 min para entender | 1-2 horas para aplicar

## ⚡Como Aplicar
1.  **Início do processo**: O GPT é iniciado e verifica a existência do diagnóstico dos canais do cliente.
2.  **Acionamento do Briefing**:
    *   Se o diagnóstico não existir, o GPT imediatamente inicia o briefing.
    *   Se o diagnóstico existir, mas após a interpretação, o GPT determinar que os dados são insuficientes para entender o contexto do projeto, ele também partirá para o briefing.
3.  **Realização do Briefing**: O GPT fará uma série de perguntas centrais ao usuário, focadas em compreender o contexto do projeto digital.
4.  **Coleta de Informações**: O GPT coleta todas as informações necessárias fornecidas pelo usuário durante o briefing.
5.  **Próxima Etapa**: Após a coleta de dados suficientes no briefing, o processo avança para a fase de investigação de objetivos.

## 💡 Exemplos Práticos
O GPT, ao perceber a ausência de um diagnóstico detalhado, pode perguntar: "Qual o objetivo principal deste projeto digital? Qual o público-alvo que você pretende atingir? Quais os principais desafios que você enfrenta atualmente com seus canais?"

## Consideracoes
O briefing serve como uma etapa de coleta de dados fundamental quando informações prévias (como um diagnóstico de canais) estão ausentes ou são insuficientes, garantindo que o GPT tenha o conhecimento necessário para proceder com a definição estratégica de objetivos.
