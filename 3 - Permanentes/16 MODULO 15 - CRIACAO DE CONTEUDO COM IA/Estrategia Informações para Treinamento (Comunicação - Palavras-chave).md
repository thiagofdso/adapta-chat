# Estrategia Informações para Treinamento (Comunicação - Palavras-chave)

## �� Categoria
Estrategia

## 📌 Sumário Executivo
Listar para a IA todas as palavras-chave de cauda longa e cauda curta relevantes para o projeto ou estratégia.

## �� Descricao
"E, por último, a última informação da estratégia, de fato, que a gente vai instruir, é as palavras-chaves, onde a gente vai listar para o chat epT todas as palavras-chave de cauda longa e de cauda curta do nosso projeto, da estratégia ou do cliente. Beleza? Então, isso aqui é fundamental."

## Complexidade
Intermediario

## ⏱️ Templo de implementação
1-5 min para entender | 1-2 horas para aplicar

## ⚡Como Aplicar
1.  Identificar todas as palavras-chave de cauda longa e cauda curta relevantes para o projeto ou cliente.
2.  Listar essas palavras-chave para o Chat GPT como parte das informações de treinamento da estratégia, utilizando o GPT Builder.

## 💡 Exemplos Práticos
Durante a fase de geração de ideias, o Chat GPT pode ser instruído a listar as "20 melhores palavras-chaves da doutora Mariana", e então a partir dessa lista, palavras como "Tratamentos naturais para a menopausa" podem ser usadas como base para gerar novas ideias de conteúdo.
