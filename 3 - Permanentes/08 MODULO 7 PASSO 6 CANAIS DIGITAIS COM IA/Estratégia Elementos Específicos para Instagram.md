# Estratégia Elementos Específicos para Instagram

## 🎯 Categoria
Estrategia

## 📌 Sumário Executivo
O GPT sugere para o Instagram: tipos de stories, lista de hashtags, ideias de reels, sugestão de bio, link na bio e sua estrutura, e destaques estratégicos para simular a jornada de compra.

## 📝 Descricao
Existem elementos específicos que o GPT deve trazer para o canal Instagram como parte da estratégia digital. Ele traz tipos de stories relevantes que devem ser usados baseados na jornada de compra, uma lista de hashtags, ideias de formatos de reels, sugestão de bio, e a estrutura de links na bio. Além disso, ele sugere qual deve ser o link a ser colocado na bio e qual a estrutura da página de links. Por último, ele indica destaques estratégicos para serem colocados no perfil, com o objetivo de modelar e simular a jornada de compra das personas.

## Complexidade
Intermediario

## ⏱️ Templo de implementação
10-15 min para entender | 1-2 horas para aplicar

## ⚡Como Aplicar
O GPT, após receber a entrada de dados padrão (objetivos, DNAs, tom de voz, SWOT, persona e jornada de compra) e realizar uma investigação de recursos, define a estratégia para cada canal digital. No caso do Instagram, o GPT automaticamente gera os seguintes elementos específicos:
1.  **Sugestão de Stories:** Define tipos de stories relevantes baseados na jornada de compra.
2.  **Lista de Hashtags:** Oferece sugestões de hashtags.
3.  **Ideias de Reels:** Apresenta ideias de formatos de reels.
4.  **Sugestão de Bio:** Propõe um texto para a biografia do perfil.
5.  **Link na Bio e Estrutura de Links:** Sugere o link principal a ser colocado na bio e detalha a estrutura da página de links.
6.  **Destaques Estratégicos:** Propõe destaques para o perfil que visam simular a jornada de compra das personas.

## 💡 Exemplos Práticos
*   **Stories:** Tipos de stories relevantes que se alinham com a jornada de compra do público.
*   **Hashtags:** Uma lista de hashtags apropriadas para o conteúdo e o público-alvo.
*   **Reels:** Ideias de formatos de vídeos curtos para engajamento e alcance.
*   **Bio:** Texto conciso e estratégico para a descrição do perfil.
*   **Link na Bio:** O link principal para uma página com múltiplos links e a organização dessa página (ex: links para produtos, materiais gratuitos, outros canais).
*   **Destaques:** Destaques no perfil organizados para guiar o usuário através de uma "jornada de compra virtual" dentro do próprio Instagram.
