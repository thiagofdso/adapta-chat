# Estratégia Elementos Específicos para Blog

## 🎯 Categoria
Estratégia

## �� Sumário Executivo
O GPT, ao definir a estratégia para um Blog, além dos elementos obrigatórios comuns a todos os canais digitais, adiciona sugestões de layout e estrutura de navegação específicas para otimizar o desempenho e alinhamento do blog com a estratégia digital global.

## 📝 Descricao
A estratégia para o Blog, conforme elaborada pelo GPT de canais digitais, incorpora elementos obrigatórios que se aplicam a todos os canais. Estes incluem a definição da frequência de publicações e do formato do conteúdo a ser utilizado. Os objetivos do canal são delineados, sendo derivados do objetivo macro do projeto e refletindo o papel específico que o Blog desempenhará dentro desse contexto maior. O GPT também define o papel do Blog na jornada de compra do cliente, sugerindo tipos de conteúdos que devem ser empregados, acompanhados de justificativas estratégicas e exemplos de formatos. Um guia de ação é fornecido, apresentando um manual de diretrizes para a condução do canal. A estrutura de linguagem é definida para orientar a comunicação no Blog, e uma identidade visual estratégica é estabelecida, focando nas linguagens visuais e na sensação que deve ser transmitida, em vez de detalhes como fonte ou cor. Para o Blog especificamente, são adicionadas sugestões de layout e de estrutura de navegação do blog.
