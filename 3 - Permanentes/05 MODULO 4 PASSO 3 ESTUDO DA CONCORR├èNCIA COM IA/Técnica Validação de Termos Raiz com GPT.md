# Técnica Validação de Termos Raiz com GPT

## 📌 Sumário Executivo
Descreve o método interativo onde o GPT sugere termos raiz para um projeto, que são então validados pelo usuário. Se os termos não forem aprovados, o GPT gera novas sugestões até que a validação seja bem-sucedida, permitindo a internalização e prosseguimento para a definição de termos derivados.

## 📝 Descricao
A técnica de Validação de Termos Raiz com GPT é um processo interativo que se inicia quando o usuário solicita ao ChatGPT a geração de termos raiz para o projeto. O GPT, atuando como um custom GPT (agente), elabora uma série de termos principais que representam o universo temático do projeto. Após a geração, esses termos são submetidos a um processo de validação com o usuário. Caso os termos propostos não sejam considerados válidos ou relevantes pelo usuário, o GPT é instruído a gerar uma nova rodada de termos raiz, repetindo o ciclo. Este loop de geração e validação continua até que os termos raiz sejam aprovados. Uma vez validados, o GPT os "internaliza", ou seja, considera-os definidos e pode então avançar para a próxima etapa, que é a definição de termos derivados e de cauda longa. Esta validação garante que os termos fundamentais estejam alinhados com as expectativas e o escopo do projeto, direcionando a pesquisa de concorrência de forma mais precisa.

*01. A LÓGICA DO GPT - ESTUDO DA CONCORRÊNCIA*
> "Se a gente pede para o chat epT gerar os termos raiz, ele vai passar por uma validação. Então, ele vai gerar o termo de raiz e vai validar com a gente. Se não tiver validado, ele vai gerar de novo mais termos raiz. Se tiver validado, ele vai para a etapa de definir os termos raiz. Então, ele vai internalizar que esses termos raiz."

## ⚡Como Aplicar
1.  Acessar o GPT customizado para termos do projeto.
2.  Solicitar ao GPT a geração dos termos raiz para o projeto.
3.  Avaliar os termos raiz gerados pelo GPT.
4.  Se os termos forem aprovados, confirmar a validação com o GPT. Ele internalizará os termos e seguirá para as próximas etapas (geração de termos derivados).
5.  Se os termos *não* forem aprovados, solicitar ao GPT que gere novos termos raiz, repetindo a avaliação até a validação.
