# Ferramenta GPT Customizado para Critérios de Concorrentes

## 🎯 Categoria
Ferramenta

## 📌 Sumário Executivo
Um GPT customizado que, a partir dos termos, DNAs e objetivos do projeto, sintetiza e define critérios para identificar concorrentes relevantes e alinhados ao universo temático e aos objetivos, filtrando perfis fora do escopo.

## 📝 Descricao
A Ferramenta GPT Customizado para Critérios de Concorrentes é um agente de inteligência artificial desenhado para auxiliar na definição precisa do que constitui um concorrente relevante para um projeto digital. Para operar, o usuário deve alimentar o GPT com os termos do projeto previamente gerados (palavras-chave e expressões do universo temático que ajudam a nichar a pesquisa), todos os DNAs (elementos de identidade e diferenciação do projeto) já definidos, e os objetivos estabelecidos do projeto. O GPT, então, processa essas informações.

Primeiro, ele entende que os concorrentes devem estar inseridos no universo temático definido pelos termos. Em seguida, ele compara aquele universo temático com os DNAs do projeto e com os objetivos. O propósito dessa comparação é criar um conjunto de critérios de concorrentes que não apenas estejam dentro do tema, mas também alinhados com o DNA do especialista ou do projeto. Por exemplo, se o GPT identificar um portal que produz conteúdo sobre "construção para venda", mas que "não vende nenhum produto" ou "não é um creator", essa síntese com o DNA permite excluí-lo como concorrente, pois não se alinha ao perfil desejado. Adicionalmente, ele filtra concorrentes que possam comprometer a atingir os objetivos do projeto, focando em pessoas que realmente têm a chance de impactar o negócio. O resultado final é uma lista assertiva de critérios para a identificação de concorrentes.

## Complexidade
Intermediário

## ⏱️ Templo de implementação
10-20 min para entender | 1-2 horas para aplicar

## ⚡Como Aplicar
1.  **Fornecer Termos do Projeto**: Insira no GPT os termos do projeto previamente gerados (termos raiz, derivados e de cauda longa) que delimitam o universo temático.
2.  **Fornecer DNAs**: Inclua todos os documentos ou descrições dos DNAs (elementos de identidade e diferenciação) que foram definidos para o seu projeto ou o do seu cliente.
3.  **Fornecer Objetivos do Projeto**: Comunique claramente os objetivos específicos que o projeto busca alcançar.
4.  **Processamento pelo GPT**: O GPT utilizará essas informações para comparar, sintetizar e criar critérios que reflitam concorrentes dentro do universo temático, alinhados ao DNA e aos objetivos, excluindo perfis irrelevantes ou desalinhados.
5.  **Revisão dos Critérios**: O resultado será uma lista detalhada de critérios de concorrentes, que pode ser usada como base para a etapa seguinte de formulação de concorrentes conhecidos e, posteriormente, para a pesquisa geral de concorrência com ferramentas como o Deep Research.

## �� Exemplos Práticos
*   Se o projeto visa "construção para venda" e tem um DNA de "creator" que vende infoprodutos, o GPT poderá identificar que um portal que apenas produz conteúdo sobre o tema, mas não vende produtos nem se posiciona como "creator", não é um concorrente relevante de acordo com os critérios definidos.
*   Para um projeto com objetivo de "escalar vendas de um infoproduto", o GPT filtrará concorrentes que, embora no mesmo nicho, não possuam ofertas similares de infoprodutos ou cujo modelo de negócio não impactaria diretamente o alcance desse objetivo.

## 📊 Metricas/Resultados
*   Geração de uma lista de critérios de concorrentes altamente assertivos e relevantes para o projeto.

## Consideracoes
A eficácia desta ferramenta depende criticamente da qualidade, clareza e completude dos inputs fornecidos (termos do projeto, DNAs e objetivos). É um agente intermediário que deve ser utilizado após a definição dos termos do projeto e antes da pesquisa efetiva de concorrência, fornecendo a base para a seleção de concorrentes.
