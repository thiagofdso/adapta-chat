# Definição e Desenho de Estratégias Digitais Complementares

O material aborda o processo de definição de estratégias digitais complementares, partindo de um ponto onde os canais digitais e a estratégia principal já foram estabelecidos. A execução é realizada através de uma ferramenta específica dentro de uma plataforma.

## Utilização do Agente de Estratégias Digitais

O processo é iniciado com o uso do "agente de estratégias digitais", descrito como o segundo agente do sexto passo dentro da plataforma Ocean.

### Função do Agente
A descrição do agente indica que sua finalidade é desenhar estratégias digitais completas e detalhadas para qualquer iniciativa digital. Para isso, ele interpreta um conjunto de documentos estratégicos do projeto para gerar execuções específicas, tais como:
- Sites
- Campanhas
- Lives
- Materiais
- Automações

Toda a geração é baseada na jornada do cliente e nas metas definidas para o projeto.

### Inputs e Outputs
O agente utiliza como input principal o resultado obtido na etapa anterior de definição dos canais digitais. Além disso, ele analisa um total de nove documentos estratégicos, sendo estes os mesmos utilizados para a definição dos canais, acrescidos de um documento sobre "jornadas digitais". O output gerado é a "estratégia de estratégias digitais" do projeto.

## Passo a Passo para o Desenho das Estratégias

O conteúdo apresenta uma sequência clara de ações para configurar e iniciar o trabalho com o agente.

1.  **Inserção dos Documentos:** O primeiro passo consiste em fornecer ao agente todos os nove documentos estratégicos necessários para a análise.
2.  **Processamento e Síntese:** Após o envio, o agente (identificado como GPT) processa e analisa todos os documentos. Ao final dessa análise, ele gera uma "síntese final".
3.  **Seleção das Estratégias:** Com a análise dos documentos concluída, o agente solicita que o usuário especifique quais estratégias digitais deseja que sejam desenhadas.
4.  **Definição das Estratégias a Serem Criadas:** O usuário, então, lista as estratégias que serão desenvolvidas. As escolhas feitas foram:
    - Site
    - Materiais educacionais
    - Fluxos de automação
    - Campanha de conversão de vendas
    - Lives

    > **Nota:** É mencionado que a "campanha de conversão de vendas" foi incluída apenas como exemplo para demonstrar a capacidade de geração do agente, pois essa função já é executada pela equipe de marketing no contexto apresentado. As "lives" também foram adicionadas posteriormente para que o resultado pudesse ser visualizado.

## Próximos Passos no Processo

Após a definição das estratégias desejadas, o agente se prepara para iniciar o desenho detalhado de cada uma delas, começando pelo mapeamento do site. O conteúdo indica que o desenvolvimento efetivo e a continuação desse desenho ocorrerão em uma etapa seguinte.

## Ferramentas Mencionadas

-   **Ocean:** A plataforma onde todo o processo é executado e onde os agentes de IA estão localizados.
-   **Agente de Estratégias Digitais:** A ferramenta de IA específica, parte do sexto passo da plataforma Ocean, utilizada para criar as estratégias digitais com base em documentos de projeto.
-   **GPT:** Mencionado como o motor de processamento que analisa os documentos fornecidos e interage com o usuário para definir as estratégias.
