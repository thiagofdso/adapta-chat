# Transferência da Estratégia de Canais para o Mapa de Conteúdo

O material detalha o processo de documentar uma estratégia de canais digitais, previamente definida, dentro de uma ferramenta chamada "Mapa de Conteúdo". A ação central é migrar todas as informações estratégicas para uma plataforma centralizada, garantindo que fiquem registradas e prontas para a fase de apresentação.

## Configuração Inicial do Mapa

O processo inicia-se na seção "apresentação da estratégia" do mapa, pois não há um local específico para a estratégia de canais na área de pesquisa estratégica. A primeira etapa é a configuração, onde itens desnecessários são removidos e apenas os relevantes para o projeto são selecionados.

Os canais e elementos estratégicos selecionados para compor o mapa são:
- Instagram
- YouTube
- Blog
- Podcast
- WhatsApp
- E-mail Marketing (cuja estrutura é adicionada em "orientações adicionais")
- Materiais educacionais
- Lives
- Mapa do site
- Estratégia do site
- Fluxo de automação

Após a seleção, os itens são reordenados para criar uma estrutura lógica, priorizando os canais digitais (Instagram, YouTube, blog, etc.) antes dos demais elementos estratégicos.

## Passo a Passo: Preenchendo as Informações do Instagram

O conteúdo demonstra o preenchimento detalhado do mapa utilizando o canal Instagram como exemplo.

1.  **Preparação do Conteúdo:** A fonte das informações é um "documento dos canais digitais". Um desafio técnico identificado é que o Mapa de Conteúdo não aceita formatação em Markdown. A solução apresentada é utilizar uma ferramenta externa, o "Chat de PT", para remover essa formatação antes de colar o texto na plataforma.

2.  **Inserção de Dados Estratégicos:** Diversos campos específicos para o Instagram são preenchidos:
    - **Frequência das publicações:** A cadência de posts é inserida.
    - **Objetivos do canal:** Quatro objetivos SMART são adicionados individualmente.
    - **Tipos de Stories:** Oito tipos de stories estratégicos são cadastrados.
    - **Hashtags:** Uma lista com 20 hashtags é inserida.
    - **Ideias de Reels:** São adicionadas sete ideias de conteúdo para Reels, como "Quanto eu lucrei com essa casa" e "Comparativo isso versus aquilo".
    - **Estrutura de Linguagem:** Cinco estruturas são definidas: Visual e direto; Narrativo e espontâneo; Desafiador e empático; Confiante e prática; Didático e acionável.
    - **Identidade Visual:** Informações sobre a identidade visual da marca são inseridas.

3.  **Simulação da Biografia do Perfil:** O mapa possui uma funcionalidade que simula a aparência do perfil do Instagram. Os seguintes dados são preenchidos para o perfil `@engenheirosdozero`:
    - **Foto de perfil:** Uma imagem é adicionada.
    - **Nome e arroba:** Engenheiros do Zero (@engenheirosdozero).
    - **Métricas:** 485 mil seguidores e 9.255 seguindo.
    - **Bio:** O texto adaptado, originalmente sugerido pelo GPT, é inserido.
    - **Link da Bio:** Um link fictício (`engenheirosdozero.com.br`) é utilizado como placeholder.

4.  **Criação dos Destaques:** O planejamento inclui a criação de 11 destaques, com títulos como "CPV de A-Z", "Metodologia", "Alunos" e "Obras". Como a ferramenta exige uma foto para cada destaque, recorre-se novamente ao GPT com o prompt "Crie imagens minimalistas para os oito destaques", anexando o estilo visual do perfil como referência para a geração das imagens. Após a criação das imagens, elas são inseridas e a seção é finalizada.

## Ferramentas Mencionadas

O processo envolve o uso de duas ferramentas principais:

-   **Mapa de Conteúdo:** A plataforma central para documentar a estratégia. Ela possui seções específicas para cada canal, campos detalhados e funcionalidades interativas, como o simulador de perfil de Instagram.
-   **Chat de PT (ChatGPT):** Utilizado como ferramenta de apoio para duas tarefas distintas:
    1.  Remover a formatação Markdown de textos para torná-los compatíveis com o Mapa de Conteúdo.
    2.  Gerar conteúdo visual, especificamente as imagens minimalistas para os destaques do Instagram, a partir de um comando de texto.

## Gestão de Informações Adicionais

É destacado que nem toda informação estratégica possui um campo correspondente no Mapa de Conteúdo. Para resolver isso, a seção **"Orientações Adicionais"** é utilizada para registrar esses dados. Exemplos de informações alocadas nesta área incluem:

-   A estratégia completa do canal Instagram.
-   A estrutura da página de links para a bio do Instagram.
-   A estratégia geral do canal YouTube.
-   As categorias para o blog sugeridas pelo GPT.

Essa prática garante que toda a estratégia fique documentada e possa ser apresentada futuramente, quando o mapa for transformado em um site.

## Conclusão do Módulo

Após o preenchimento de todos os canais (Instagram, YouTube, blog, etc.), o módulo de "Canais Digitais" é considerado concluído. O próximo passo na estratégia é a definição das **linhas editoriais do conteúdo**. O material finaliza mantendo um suspense sobre como será a apresentação final da estratégia em formato de site.
