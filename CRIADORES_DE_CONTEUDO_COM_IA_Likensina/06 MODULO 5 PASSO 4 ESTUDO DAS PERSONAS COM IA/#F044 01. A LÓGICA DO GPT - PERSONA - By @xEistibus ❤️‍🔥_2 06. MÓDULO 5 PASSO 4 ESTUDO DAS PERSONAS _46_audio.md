## A Lógica do GPT de Pesquisa de Persona

O material apresenta a lógica de funcionamento de um GPT customizado focado em pesquisa de Persona. É destacado que, embora utilize apenas um agente de IA, o processo exige a coleta manual de diversos dados (inputs) para garantir um resultado de alta qualidade. A abordagem manual é preferida em detrimento de métodos automáticos, que são considerados ainda rudimentares e inconsistentes.

### Alimentação Inicial e Contexto do Projeto

O primeiro passo no uso do GPT de persona é fornecer a ele os documentos necessários para que possa compreender o contexto do projeto. O agente solicita e processa os seguintes materiais, um por vez, apresentando um resumo após a análise de cada um:

-   **Objetivos do projeto**
-   **Os três DNAs**
-   **Diagnóstico:** Inclui tanto a análise da concorrência quanto a análise dos canais próprios (ou do cliente).
-   **Análise SWOT**

Esses documentos servem como base de treinamento para que a IA possa gerar um perfil de persona alinhado ao projeto.

### Métodos de Investigação da Persona

Após processar os documentos iniciais, o GPT pergunta ao usuário qual método de investigação de persona ele deseja seguir. Os métodos disponíveis, descritos como versões "enxugadas e unificadas", são os seguintes:

#### 1. Método de Investigação
É o método mais simples e não requer nenhum input de dados pré-coletados. O GPT faz uma série de perguntas sobre o público-alvo, e com base nas respostas fornecidas pelo usuário, ele gera o perfil da persona. A percepção do usuário sobre seu público é considerada uma fonte de informação válida e precisa para o projeto.

#### 2. Método Buyers Survey
Neste método, o input são pesquisas e formulários que já foram aplicados à audiência ou aos clientes. O usuário pode fornecer um ou mais formulários para a IA, que analisará as respostas contidas neles para construir o perfil da persona.

#### 3. Método das Palavras-Chave
O processo envolve realizar uma pesquisa de palavras-chave para identificar os termos e as buscas mais comuns dentro do nicho de mercado. Essa lista de palavras-chave é então inserida no GPT. Com base nessas informações, a IA faz uma "leitura do mercado" e cria uma hipótese sobre o perfil da persona, baseando-se no que esse público pesquisa.

#### 4. Método dos Comentários ou Relatos de Campo
Este método consiste em coletar comentários e relatos relevantes de diversas fontes para entender as nuances do público. As fontes citadas incluem:
-   Vídeos do YouTube
-   Livros
-   Fóruns
-   O site Reclame Aqui (tanto da empresa quanto de concorrentes)

Os comentários selecionados são compilados em uma planilha ou documento, que é usado como input para o GPT gerar os perfis de persona.

#### 5. Método Híbrido
Permite ao usuário combinar múltiplos métodos. É possível selecionar todos os métodos disponíveis ou escolher uma combinação específica (por exemplo, usar os dados de *Buyers Survey* e de *Comentários*). O GPT levará em consideração todos os documentos e dados dos métodos selecionados para criar um perfil de persona mais completo.

> **Nota:** Para os métodos *Buyers Survey*, *Palavras-Chave* e *Comentários*, a coleta e curadoria dos dados (formulários, listas de keywords, comentários) devem ser feitas manualmente **antes** de iniciar a interação com o GPT de pesquisa de persona.

### Passo a Passo: Geração e Validação dos Perfis de Persona

Depois que o método é escolhido e os dados são fornecidos, o agente segue um fluxo específico para criar e refinar as personas.

1.  **Análise e Geração de Grupos:** A IA analisa todas as informações coletadas e identifica diferentes grupos de público-alvo. Em seguida, gera uma primeira versão dos "grupos de personas" com uma pequena descrição para cada um, sem ainda detalhar o perfil completo.
2.  **Validação dos Grupos:** O GPT apresenta esses grupos ao usuário para validação.
3.  **Refinamento (Loop):** Se o usuário não aprovar os grupos sugeridos, o GPT entra em um ciclo de refinamento. Ele ajusta os grupos com base no feedback e os apresenta novamente para validação. Este "looping" continua até que o usuário valide os grupos de personas.
4.  **Detalhamento Final:** Após a validação dos grupos, o agente avança para a última etapa: detalhar o perfil de cada persona, uma por vez, utilizando todos os elementos do "mapa de conteúdo" para criar um perfil completo e aprofundado.
