# A Lógica dos GPTs na Criação de Estratégias

O material apresentado detalha a lógica por trás do uso de diferentes métodos — manual, Deep Research e agentes Custom — na execução de tarefas para a criação de estratégias. A abordagem se baseia na existência de um padrão que divide as ações em três tipos fundamentais. Essa compreensão ajuda a otimizar o uso da inteligência artificial não apenas para estratégia, mas para qualquer outra finalidade, incluindo a produção de conteúdo.

A explicação utiliza um mapa mental/fluxograma na ferramenta Miro para ilustrar esses conceitos.

## 1. Agregação de Dados

A primeira ação fundamental é a **agregação de dados**, que consiste em juntar informações de diversas fontes para servirem como base para trabalhos futuros. Esse processo é comparado a um "input" que precisa ser coletado e consolidado.

### Execução Manual

É recomendado que a agregação de dados seja realizada **manualmente**. O conteúdo aponta que inteligências artificiais, de forma geral, são muito ruins nessa tarefa. Mesmo aquelas com acesso à internet, como o Gemni (do Google), apresentam problemas. As principais razões para essa ineficiência são:

-   **Dados Desatualizados:** A maioria das IAs, especialmente o "chat epT", possui uma latência (atraso) nos dados, não refletindo informações em tempo real.
-   **Critérios de Relevância:** A IA não agrega conteúdo com base em critérios de mercado ou algoritmos relevantes para o usuário. Em vez disso, ela se baseia em seu próprio banco de dados e no que considera relevante, o que não corresponde necessariamente a uma pesquisa orgânica que ranquearia um conteúdo em primeiro lugar.
-   **Limitações Técnicas:** Existem limitações práticas, como a incapacidade de uma IA acessar e coletar comentários de um vídeo no YouTube.

Um exemplo prático de agregação manual de dados é a **pesquisa de palavras-chave** durante a definição da persona, onde se reúnem todos os termos relevantes para um projeto em um único lugar. A exceção mencionada é a agregação da lista de concorrentes, um tipo de dado que a IA consegue coletar.

Após a coleta manual, esses dados são fornecidos como input para a IA, que então os processa para gerar um output.

## 2. Análises Externas

O segundo tipo de ação são as **análises externas**. Após agregar os dados, é necessário analisá-los para extrair padrões e observações.

### Uso do Deep Research

Para essa tarefa, a ferramenta recomendada é o **Deep Research**. O motivo é sua capacidade analítica superior e a habilidade de processar uma maior quantidade de dados simultaneamente, realizando uma análise mais minuciosa e um "vasculhamento maior" das informações.

O Deep Research é especialmente eficaz ao analisar algo externo, como uma página web ou um vídeo. Um exemplo é, após agregar uma lista dos 20 principais conteúdos virais do YouTube de um nicho, usar o Deep Research para fazer uma análise aprofundada dos roteiros, elementos visuais e estratégias de SEO desses vídeos para identificar padrões.

## 3. Ações de Convergência

A terceira e última ação é a **convergência**, que se refere a gerar o output final. É o ato de pegar os dados já analisados e chegar a uma conclusão, ou seja, criar algo a partir da análise.

A convergência dá um destino e uma origem para a análise, transformando-a em um plano de ação concreto. A informação analisada, que por si só não significa nada, é colocada em prática.

### Uso do Agente "Custom"

Para as ações de convergência, a ferramenta utilizada é o **"Custom"** (agente customizado). A justificativa é que, nesta fase, geralmente não há necessidade de acessar dados externos. O processo se baseia em informações que já foram coletadas e analisadas, como documentos fornecidos. O "Custom" analisa esses materiais internos para chegar a um desfecho ou resultado final (outcome).

Exemplos de ações de convergência incluem:

-   Utilizar os objetivos do projeto para criar o **DNA da marca**.
-   Realizar uma pesquisa de concorrência para, em seguida, criar a **análise SWOT** do projeto.
-   Juntar todos os dados referentes à persona para criar o **perfil de persona**.

## Ferramentas Mencionadas

O material cita uma ferramenta específica que se destaca em certas tarefas:

### Manus

A **Manus** é descrita como uma ferramenta "bem poderosa" e "incrível", sendo muito boa tanto para a **agregação de dados** quanto para a **análise externa**. Sua capacidade de análise é comparada à de um humano.

No entanto, é destacado que a ferramenta ainda está em fase "embrionária" e é "muito instável". Por essa razão, ela não foi formalmente incluída no método principal, mas será abordada em uma aula futura para consulta, pois pode auxiliar significativamente nas análises externas.
