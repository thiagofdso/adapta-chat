# Gestão de Linhas Editoriais no Mapa de Conteúdo

O material apresentado descreve o processo de levar as linhas editoriais para dentro de uma ferramenta chamada **Mapa de Conteúdo**. A organização é feita de uma maneira específica para centralizar a estratégia de conteúdo.

## Acessando e Estruturando as Linhas Editoriais

Para inserir as linhas editoriais na plataforma, o caminho é acessar a sua **estratégia**, navegar até a aba de **pesquisa estratégica** e, no final desta seção, localizar a área denominada **"Linhas Editoriais"**.

Dentro dessa área, a interface organiza cada linha editorial como uma aba individual na parte superior da tela. Essa disposição permite alternar entre as diferentes linhas com um simples clique, de forma semelhante a uma planilha, mas com as abas no topo.

## Passo a Passo: Adicionando Linhas Editoriais e Assuntos

O processo para preencher as linhas editoriais dentro da ferramenta é detalhado em etapas sequenciais para garantir que nenhuma informação seja perdida.

1.  **Criar a Linha Editorial:** Para começar, clique em **"adicionar linha editorial"**. Isso criará um novo espaço para uma nova linha.
2.  **Definir o Nome:** Copie o nome da sua linha editorial de uma fonte externa (como o Notion) e cole-o no campo superior destinado ao nome.
3.  **Adicionar os Assuntos:** Abaixo do nome, clique em **"adicionar assunto"** para criar os campos onde os tópicos de cada linha editorial serão inseridos.
4.  **Preencher os Assuntos:** Copie a lista de assuntos da sua fonte original (sem a numeração) e cole-a nos respectivos campos.
5.  **Ajustar a Formatação:** Um ponto de atenção é que a ferramenta **não formata textos em Markdown**, que é o padrão usado no Notion. Por isso, é necessário **remover manualmente os "singles"** (caracteres de formatação, como negrito ou itálico) para que o texto apareça corretamente.
6.  **Salvar o Progresso:** Após inserir todos os assuntos de uma linha editorial, é fundamental clicar em **"salvar"**. Este passo garante que todo o trabalho seja gravado e não seja perdido ao sair da página.

Linhas editoriais que não serão utilizadas podem ser facilmente removidas clicando na opção de excluir.

### Ferramentas Mencionadas

O conteúdo faz referência a algumas ferramentas e métodos de organização:

-   **Mapa de Conteúdo:** A plataforma principal onde as linhas editoriais são inseridas, organizadas e gerenciadas.
-   **Notion:** Citado como a ferramenta de origem onde as linhas editoriais e seus respectivos assuntos são elaborados. É ressaltado que sua formatação (Markdown) precisa ser ajustada manualmente ao ser transferida.
-   **Mapas Mentais:** Apresentados como uma metodologia alternativa para elaborar e visualizar as linhas editoriais. A ferramenta permite a integração desses mapas.

### Método Alternativo com Mapas Mentais

Para quem prefere definir as linhas editoriais usando um mapa mental, a plataforma oferece uma alternativa à inserção manual. Há uma descrição clicável: **"Se você utiliza mapas mentais para elaborar suas linhas editorais, clica aqui"**.

Ao clicar, é possível inserir um **link para o mapa mental** ou até mesmo carregar **imagens** dele. O benefício dessa abordagem é consolidar e "concatenar" toda a estratégia dentro do Mapa de Conteúdo, evitando que as informações fiquem espalhadas por diferentes lugares.

## Próximo Passo: Definição do Funil de Conteúdo

Após organizar as linhas editoriais na ferramenta, o passo seguinte é a definição do **funil do conteúdo**.

Este processo consiste em analisar as linhas editoriais, seus assuntos e temas, e distribuí-los estrategicamente dentro das etapas do funil de marketing. O objetivo é definir qual conteúdo pertence ao **topo do funil (etapa de atração)** e qual se encaixa no **fundo do funil (etapa de conversão)**. Essa classificação ajuda a focar o uso de cada linha editorial de acordo com os objetivos de cada estágio da jornada do cliente.
