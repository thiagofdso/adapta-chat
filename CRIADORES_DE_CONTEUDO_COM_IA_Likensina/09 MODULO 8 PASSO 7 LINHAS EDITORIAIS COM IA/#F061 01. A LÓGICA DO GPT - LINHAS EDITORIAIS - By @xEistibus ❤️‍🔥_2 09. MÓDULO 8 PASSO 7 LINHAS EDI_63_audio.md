O conteúdo aborda a utilização do Chat EPT para auxiliar na definição estratégica de linhas editoriais para um projeto. O processo é estruturado e utiliza diferentes GPTs e métodos para garantir que o conteúdo final atinja os objetivos propostos.

## Ferramentas Mencionadas

O material descreve o uso de duas abordagens de GPT distintas para o processo:

- **GPT Customizado de Linhas Editoriais:** É a ferramenta principal, um GPT personalizado responsável por consolidar as informações e definir as linhas editoriais finais do projeto.
- **GPT Intermediário para Análise de Conteúdos Virais (Deep Research):** Não é um agente customizado, mas sim o uso do chat padrão com um prompt específico para realizar uma análise aprofundada ("Deep Research"). Sua função é analisar os links de conteúdos virais fornecidos para identificar padrões e extrair insights que serão usados como um dos insumos para o GPT principal.

## Estrutura de uma Linha Editorial

A apresentação detalha que uma linha editorial possui uma estrutura hierárquica, composta por diferentes níveis de profundidade. Ela é dividida da seguinte forma:

- **Linha Editorial:** Representa o macro tema, o tópico principal e mais amplo.
  - *Exemplo:* Captação de recursos.
- **Assuntos:** São as subdivisões da linha editorial, representando tópicos derivados que existem dentro do macro tema. Uma linha editorial é composta por vários assuntos.
  - *Exemplo (dentro de "Captação de recursos"):* Financiamento Caixa, Financiamento Banrisul.
- **Temas:** São os micro temas, representando derivações específicas dentro de cada assunto.
  - *Exemplo (dentro de "Financiamento Caixa"):* Composição de renda, FGTS.

Essa estrutura completa, do macro tema aos micro temas, compõe a linha editorial detalhada.

## Passo a Passo para a Definição das Linhas Editoriais

O processo para definir as linhas editoriais com o auxílio do GPT segue uma sequência lógica e metódica, dividida em etapas claras.

### 1. Análise do Projeto e Definição dos Tipos de Linha Editorial

A primeira ação do GPT, após processar os documentos do projeto, é analisar o contexto e definir quais tipos de linha editorial são mais pertinentes para a natureza daquele projeto específico. Todas as ideias subsequentes de linhas editoriais serão baseadas nesses tipos selecionados. Os nove tipos de linhas editoriais existentes mencionados no material são:

- Linha técnica
- Linha editorial científica
- Linha editorial educacional
- Linha editorial educacional
- Linha editorial motivacional
- Linha editorial cultural
- Linha editorial de estilo de vida
- Linha editorial de entretenimento
- Linha editorial de tutorial
- Linha editorial de notícias

### 2. Brainstorm de Ideias de Linhas Editoriais

Após a aprovação dos tipos, o GPT utiliza três métodos distintos, um de cada vez, para gerar um brainstorm de ideias. Para cada método, o processo é o mesmo: se as linhas geradas forem validadas, ele avança para o próximo método; caso contrário, ele refaz o método atual com base no feedback recebido até que o resultado seja validado.

- **Método 1: Baseado na Persona e na Jornada de Compra**
  - O GPT utiliza as informações dos documentos de persona e de jornada de compra para propor uma gama de linhas editoriais que façam sentido para o público-alvo e suas etapas de decisão.

- **Método 2: Baseado em Palavras-chave**
  - As palavras-chave e termos relevantes do projeto são inseridos no GPT. Com base nesse universo temático, ele gera ideias adicionais de linhas editoriais.

- **Método 3: Baseado na Análise de Conteúdos Virais**
  - O GPT propõe linhas editoriais a partir de uma análise de conteúdos que performaram bem no mercado. Essa análise é gerada previamente pelo GPT intermediário (Deep Research), que processa os links de conteúdos virais de concorrentes e do próprio cliente. A análise identifica padrões, alavancas exponenciais e cria uma "fórmula" do que funciona e do que não funciona. O resultado dessa análise é então inserido no GPT principal para gerar mais ideias.

### 3. Curadoria e Redução do Escopo

Após a execução dos três métodos, o GPT terá gerado um grande volume de ideias, muitas das quais podem ser redundantes ou parecidas. Nesta fase, ele realiza um "pente fino" no material. O objetivo é remover repetições e fazer uma curadoria final para selecionar as linhas editoriais que mais fazem sentido. O resultado final é uma lista com **4 a 12 linhas editoriais**, escolhidas com base em critérios de alinhamento com o projeto.

### 4. Detalhamento das Linhas Editoriais

Uma vez que a lista final de linhas editoriais é validada, o GPT inicia a última etapa: o detalhamento. Ele trabalha em uma linha editorial por vez, definindo para cada uma delas quais são os **assuntos** e, dentro de cada assunto, quais são os **temas** correspondentes, seguindo a estrutura hierárquica explicada.
