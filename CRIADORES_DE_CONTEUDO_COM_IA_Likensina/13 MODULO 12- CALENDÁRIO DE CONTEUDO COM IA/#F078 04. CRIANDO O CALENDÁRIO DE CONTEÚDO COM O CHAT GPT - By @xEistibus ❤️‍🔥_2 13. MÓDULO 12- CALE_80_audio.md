## Criação de Calendário de Conteúdo com GPT e Integração com Notion

O material detalha um processo completo para a criação de um calendário de conteúdo para canais digitais, utilizando um GPT especializado e, posteriormente, integrando os dados gerados em uma base de dados no Notion.

### Interação com o Agente GPT para Planejamento

O processo é iniciado no Notion, onde um link para o "agente de calendário de conteúdo" (Agente 19) é acionado. Este agente é um GPT descrito como um planejador editorial e estratégico, projetado para criar calendários de conteúdo sob medida. Sua função é processar documentos essenciais de um projeto (como diretrizes, tom de voz, funil, objetivos e linhas editoriais) para gerar ideias originais, organizadas por formato e mês.

O fluxo de interação com o GPT se dá da seguinte forma:

1.  **Iniciação:** O comando "criar calendário de conteúdo" é enviado ao GPT.
2.  **Carregamento e Análise de Documentos:** O GPT solicita os documentos estratégicos do projeto. Após o carregamento, ele realiza uma leitura e gera um resumo interpretativo (síntese) de todo o material para confirmar o entendimento antes de prosseguir.
3.  **Definição do Escopo:** Com os documentos processados, o GPT faz perguntas para refinar a tarefa:
    *   **Canal:** Pergunta para qual canal o calendário deve ser criado. No caso apresentado, a escolha é "YouTube".
    *   **Período:** Solicita a quantidade de meses desejada. A escolha é por "dois meses" (junho e julho).
    *   **Análise de Desempenho:** Questiona se há documentos de análise de desempenho (resultados bons e ruins) e se devem ser utilizados. O conteúdo confirma o desejo e anexa um documento específico de "Análise de resultado YouTube".
4.  **Confirmação de Diretrizes:** Após analisar o documento de desempenho, o GPT apresenta um resumo das diretrizes extraídas para validação final. Essas diretrizes incluem:
    *   Formatos de conteúdo para o canal (ex: Vídeos técnicos, Aulas profundas).
    *   Frequência de publicação mensal.
    *   Distribuição de conteúdo por linha editorial.
    O usuário confirma essas informações para que o GPT inicie a geração do calendário.

### Geração e Refinamento do Calendário

Inicialmente, o GPT sugere gerar o conteúdo separadamente para cada formato. No entanto, para o YouTube, que possui um volume menor de publicações comparado a outras plataformas como o Instagram, é solicitado que o calendário seja gerado de forma unificada ("tudo de uma vez").

O GPT então entrega uma tabela com as ideias de conteúdo para o primeiro mês (junho), contendo colunas como:

*   Título
*   Canal
*   Formato
*   Data de Publicação
*   Estratégia
*   Etapa do Funil
*   Tipo de Conteúdo

Após a primeira geração, é realizado um processo de revisão e solicitação de ajustes:

*   **Ajuste de Colunas:** Pede-se a alteração da coluna "Etapa do Funil" para os termos "topo", "meio" e "fundo", visando a compatibilidade com a estrutura do Notion.
*   **Reformulação de Conteúdo:** Algumas ideias de títulos são consideradas insatisfatórias ou "nebulosas". São fornecidas novas direções e exemplos de headlines mais alinhadas à estratégia, como substituir um título sobre "permuta" por algo relacionado a "como construir 11 casas sem ter dinheiro".
*   **Formato da Data:** É solicitado que o formato da data seja alterado para "dia/mês/ano" (com o ano em quatro dígitos) para facilitar a importação posterior.

O GPT processa as alterações e gera uma nova versão revisada do calendário.

### Passo a Passo: Transferindo o Calendário do GPT para o Notion

O material descreve um método detalhado para mover a tabela gerada pelo GPT para uma base de dados já existente no Notion, uma vez que a cópia e colagem direta não funciona adequadamente.

1.  **Colar e Transformar:** Copie a tabela do GPT e cole-a em uma página vazia do Notion. Em seguida, utilize a função "transformar em bases de dados". Isso criará uma nova base de dados simples com o conteúdo.

2.  **Ajustar Tipos de Propriedade:** Na nova base de dados, é necessário converter o tipo de propriedade de cada coluna para corresponder à base de dados de destino:
    *   Colunas como "Formato", "Etapa do Funil" e "Tipo de Conteúdo" devem ser alteradas do tipo "Texto" para o tipo "Seleção" (Select/Tag).
    *   A coluna de data deve ser alterada para o tipo "Data". O material ressalta que o formato da data deve estar correto (com ano de quatro dígitos, ex: `03/06/2025`) para que a conversão funcione.

3.  **Copiar Conteúdo (Exceto Relações):** Selecione todas as linhas da nova base de dados (que agora está com as propriedades corretas) e cole-as na base de dados principal do calendário.
    > **Nota:** Colunas do tipo "Relação" (como a de "Linhas Editoriais") não são transferidas nesse processo e precisam ser preenchidas manualmente.

4.  **Corrigir Datas (se necessário):** Caso as datas não sejam transferidas corretamente, um método de correção é apresentado:
    *   Ordene tanto a base de dados de origem (temporária) quanto a de destino (principal) em ordem alfabética crescente pela coluna "Título".
    *   Com as duas tabelas alinhadas pela mesma ordem, copie apenas a coluna de datas da tabela de origem e cole-a na coluna correspondente da tabela de destino.

5.  **Finalização Manual:** Após a transferência dos dados, duas tarefas manuais são necessárias para cada novo item:
    *   **Aplicar Template:** Abrir cada nova página e aplicar o template correspondente (ex: "template de YouTube").
    *   **Preencher Relações:** Preencher manualmente a coluna de "Linhas Editoriais", relacionando cada ideia de conteúdo à sua respectiva linha.

O processo é repetido para o segundo mês (julho), seguindo exatamente a mesma lógica de geração, revisão e importação.

### Conclusão do Processo

Ao final, o calendário de conteúdo para o YouTube está totalmente estruturado para dois meses dentro do Notion, com todas as ideias, datas e metadados organizados. O material conclui ressaltando que, embora a revisão humana seja sempre essencial para garantir que as datas e os conteúdos façam sentido, o uso do GPT **acelera o processo de construção do calendário em até 10 vezes**.

Com a finalização desta etapa, o módulo de criação de calendário é concluído, permitindo avançar para os passos complementares da estratégia abordados nos módulos seguintes do curso.
