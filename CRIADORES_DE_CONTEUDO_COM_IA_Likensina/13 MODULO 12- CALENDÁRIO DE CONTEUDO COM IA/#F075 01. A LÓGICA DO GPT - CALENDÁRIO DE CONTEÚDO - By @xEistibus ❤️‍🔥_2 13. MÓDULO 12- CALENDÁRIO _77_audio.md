Com base no material apresentado, é detalhado um sistema para a criação de calendários de conteúdo utilizando um agente de inteligência artificial específico, conhecido como "GPT de calendário". O foco está em como este agente funciona, os dados que ele requer e como ele se integra a um ecossistema de gerenciamento de projetos e conteúdo.

## O GPT de Calendário e seu Propósito

O conteúdo introduz um agente de IA especializado, o "GPT de calendário", que é treinado especificamente para a criação de calendários de conteúdo. É crucial entender a sua finalidade e distinção em relação a outros agentes.

### Agente de Estratégia vs. Agente de Produção

- **GPT de Calendário (Estratégia):** Este é um agente único, já treinado, cujo propósito principal é criar um calendário de conteúdo como um **entregável de um projeto de estratégia**. Ao vender uma estratégia para um cliente, um calendário de 3 a 6 meses é fornecido para que o cliente tenha um plano de execução pronto. Este agente é usado pontualmente para essa finalidade.

- **Agentes de Produção de Conteúdo:** São agentes diferentes, que cada usuário cria e treina para seus clientes ou projetos específicos. Esses agentes são alimentados com os documentos da estratégia daquele projeto e são utilizados no dia a dia para gerar ideias e calendários contínuos. O uso destes é recomendado para a execução frequente, pois evita o retrabalho de treinar o agente a cada nova necessidade.

O uso do "GPT de calendário" para tarefas do dia a dia é possível, mas considerado menos prático, pois exigiria reenviar e reprocessar todos os documentos estratégicos a cada vez. A recomendação é usar os agentes de produção personalizados para clientes com gerenciamento contínuo e reservar o "GPT de calendário" para a entrega pontual da estratégia.

## O Processo de Criação do Calendário

A interação com o "GPT de calendário" segue uma lógica estruturada, visualizada em uma ferramenta chamada Miro. O processo é dividido em etapas claras, desde a alimentação de dados até a geração do produto final.

### Insumos Necessários (Entradas)

Para que o agente crie um calendário alinhado à estratégia, ele precisa processar um conjunto específico de documentos. Os insumos fornecidos são:

- DNA
- Tom de Voz
- Linhas Editoriais
- Canais
- Funil

O documento central são as **Linhas Editoriais**, pois elas definem os temas sobre os quais o conteúdo será criado. As outras informações (DNA, tom de voz, etc.) são complementares e servem para garantir que as ideias de conteúdo geradas estejam alinhadas à identidade do projeto, usem a voz correta e sejam distribuídas adequadamente entre os canais e as etapas do funil.

Notavelmente, documentos como **Persona** e **Jornada de Compra** não são fornecidos nesta etapa, pois as linhas editoriais já fornecem a direção temática necessária para o agente.

### Passo a Passo da Interação com o Agente

1.  **Fornecimento dos Documentos:** O usuário envia cada um dos documentos de insumo (DNA, Tom de Voz, etc.) um de cada vez. O agente interpreta cada arquivo, solicita o próximo e, ao final, gera uma síntese do que foi processado.
2.  **Coleta de Parâmetros:** O agente inicia uma coleta de informações para definir o escopo do calendário, fazendo as seguintes perguntas:
    - Para qual canal o calendário deve ser criado (ex: Instagram)?
    - Para quantos meses o calendário deve ser planejado?
    - Qual o período exato (data de início e fim)?
3.  **Análise de Resultados (Opcional):** O agente pergunta se existe alguma análise de resultados anterior. Se houver, o usuário pode enviar o relatório para que o novo calendário seja criado com base nesses aprendizados. Caso não haja, basta informar que não tem, e o processo segue normalmente.
4.  **Confirmação das Informações:** Antes de gerar o calendário, o agente apresenta um bloco de confirmação. Ele resume as linhas editoriais que serão usadas no canal selecionado e a frequência de cada uma. Isso serve para que o usuário valide se a interpretação do agente está correta.
5.  **Geração do Calendário:** Após a confirmação do usuário, o agente gera o calendário final.

## Formato do Calendário e Integração com Ferramentas

O resultado entregue pelo agente e sua integração em um fluxo de trabalho maior são pontos chave do sistema.

### O Formato de Tabela

O calendário é gerado em um formato de **tabela**. A razão para isso é a praticidade: a tabela pode ser facilmente copiada e colada diretamente em uma base de dados no Notion, populando automaticamente o sistema de gerenciamento.

### Ecossistema de Templates

A apresentação descreve um sistema de gerenciamento que utiliza dois templates principais:

- **Template de Gestão da Estratégia (gest):** Usado para controlar as estratégias, demandas e a organização geral dos projetos.
- **Template de Gestão do Conteúdo:** Similar ao "gest", mas focado no controle do ecossistema de produção de conteúdo, seja para projetos próprios ou de clientes.

A lógica de uso é a seguinte: ao criar uma estratégia para um novo cliente, ele é cadastrado no "Template de Gestão do Conteúdo" com o status de "cliente de estratégia". O calendário gerado pelo GPT é inserido neste contexto. Isso é importante porque, nesse status, os conteúdos do calendário **não entram automaticamente no fluxo de produção**.

Posteriormente, se o cliente fechar um contrato de gerenciamento contínuo, seu status pode ser alterado. Com essa mudança, todo o conteúdo previamente planejado no calendário estratégico entra no fluxo de produção para ser executado.

O objetivo final é **integrar** o "Template de Gestão do Conteúdo" com o "Template de Gestão da Estratégia". O calendário é inserido em uma página de documentos do template de estratégia, e essa página é sincronizada com o template de conteúdo. Dessa forma, o calendário alimenta automaticamente o sistema de gestão e fica visível em ambos os locais.

### Ferramentas Mencionadas

- **GPT de Calendário:** O agente de IA central para a criação pontual de calendários de conteúdo estratégico.
- **Miro:** Ferramenta de quadro branco digital utilizada para mapear e explicar a lógica de funcionamento do processo.
- **Notion:** Software onde o calendário final, em formato de tabela, é inserido para se integrar a uma base de dados e ao sistema de gestão.
- **Template de Gestão da Estratégia (gest):** Sistema de organização para o gerenciamento de projetos de estratégia.
- **Template de Gestão do Conteúdo:** Sistema de organização para o gerenciamento e produção de conteúdo, que funciona de forma integrada ao template de estratégia.
