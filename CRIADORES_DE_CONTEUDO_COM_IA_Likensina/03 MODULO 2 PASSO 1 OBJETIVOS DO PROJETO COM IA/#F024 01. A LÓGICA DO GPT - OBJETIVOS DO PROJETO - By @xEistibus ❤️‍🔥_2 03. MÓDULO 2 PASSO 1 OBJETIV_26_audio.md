# A Lógica do GPT para Definição de Objetivos de Projeto

O material apresentado introduz o conceito de "A Lógica do GPT", uma aula que serve como base para cada módulo de uma estratégia de conteúdo com IA. O objetivo dessa explicação é detalhar o funcionamento e a lógica por trás da construção de cada passo da estratégia, permitindo um mergulho específico nos agentes, prompts e ferramentas utilizadas. A compreensão dessa lógica é apresentada como um princípio fundamental que ajuda o usuário a obter uma performance melhor ao utilizar o agente, pois ele passa a entender como a ferramenta pensa e funciona.

O foco específico do conteúdo é a lógica do agente de "Objetivos do Projeto".

## O Fluxo de Funcionamento do Agente

O funcionamento do agente é ilustrado através de um fluxograma que detalha cada etapa do processo, desde o input inicial até a geração do resultado final.

### Input Inicial e o Diagnóstico

O processo do agente começa com um input central: o **diagnóstico dos canais do cliente**. A metodologia da estratégia de conteúdo prevê que um diagnóstico inicial seja feito antes de prosseguir. Este diagnóstico pode servir como o insumo inicial para o GPT definir os objetivos do projeto.

No entanto, o material esclarece que o GPT foi adaptado para funcionar de duas maneiras:

1.  **Com Diagnóstico:** O agente recebe o diagnóstico e inicia seu trabalho a partir da interpretação desses dados.
2.  **Sem Diagnóstico:** Caso o diagnóstico não exista, o agente inicia o processo de uma forma alternativa.

É mencionado que, embora a metodologia padrão inclua essa tarefa, ela não está presente no workflow principal da ferramenta "Notion" descrita.

### Briefing com o Usuário

O agente recorre a um briefing em duas situações:

-   Quando o diagnóstico dos canais do cliente **não existe**.
-   Quando o diagnóstico existe, mas **não revela dados suficientes** para que o agente compreenda o contexto do projeto.

Nesse briefing, o agente faz uma série de perguntas centrais ao usuário para coletar informações e entender do que se trata o projeto digital e onde ele se situa.

### Fase de Investigação

Após obter um entendimento contextual do projeto (seja através de um diagnóstico suficiente ou da conclusão do briefing), o agente avança para a fase de **investigação**.

Nesta etapa, ele começa a perguntar diretamente ao usuário quais são os objetivos do projeto. Para facilitar as respostas e aprofundar a coleta de informações, o agente utiliza uma técnica de quebrar uma grande problemática em **sub-perguntas** e **sub-sub-perguntas**. Ele continua este processo investigativo até considerar que possui insumos suficientes para as próximas etapas.

### Cruzamento de Dados e Geração dos Objetivos

Após a investigação, o GPT executa silenciosamente um **cruzamento de dados**. Nesta fase, ele realiza as seguintes ações:

-   **Linka os insumos:** Une todas as informações fornecidas pelo usuário.
-   **Combina as fontes:** Os insumos são formados pela união dos dados provenientes da **interpretação do diagnóstico** (se houver) e das respostas coletadas no **briefing**, com as informações obtidas durante a **investigação**.

Baseado na congruência e na união desses dois conjuntos de dados, o agente gera os **objetivos do projeto**, seguindo uma estrutura específica que lhe foi ensinada.

# Passo a Passo do Funcionamento do Agente

O processo lógico do agente pode ser resumido nas seguintes etapas sequenciais:

1.  **Início e Verificação do Input:** O agente é iniciado e verifica se existe um "diagnóstico dos canais do cliente" como insumo.
2.  **Interpretação ou Briefing:**
    -   **Se o diagnóstico existe:** O agente o interpreta. Se os dados forem insuficientes, ele prossegue para um briefing com o usuário.
    -   **Se o diagnóstico não existe:** O agente parte diretamente para o briefing com o usuário para entender o contexto do projeto.
3.  **Investigação:** Após ter informações contextuais suficientes, o agente inicia uma investigação estruturada, fazendo perguntas e sub-perguntas sobre os objetivos desejados.
4.  **Cruzamento de Dados:** De forma interna, o agente combina as informações contextuais (do diagnóstico e/ou briefing) com os dados coletados na investigação.
5.  **Geração do Resultado:** Com base na análise combinada, o agente gera e apresenta os objetivos do projeto em um formato pré-definido.

# Estrutura da Apresentação dos Objetivos

O material detalha exatamente como o GPT estrutura a sua resposta final ao apresentar os objetivos do projeto. A geração do resultado segue a seguinte hierarquia:

### 1. Objetivos Principais
- Corresponde ao objetivo principal que se deseja alcançar com o projeto.

### 2. Objetivos Secundários
- São descritos como metas intermediárias. São objetivos que precisam ser alcançados para que o objetivo principal seja atingido.

### 3. Ações Estratégicas do Projeto
- Consiste em uma lista de ações que precisam ser implementadas no projeto. A execução dessas ações visa atingir os objetivos secundários e, por consequência, o objetivo principal.
