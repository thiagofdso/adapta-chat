# Exportação de Conteúdo no Ocean

O material apresentado detalha dois processos distintos para exportar informações da ferramenta Ocean, dependendo da natureza do conteúdo: se é puramente textual ou se constitui uma base de dados.

## Exportando Conteúdo Textual (Ex: Perfil de Persona)

Quando o conteúdo a ser exportado é composto inteiramente por texto, sem a estrutura de uma base de dados, o procedimento é direto. Este caso se aplica a páginas que contêm textos, tabelas ou fotos diretamente no corpo do documento, como um "perfil da Byer Persona".

Para este tipo de conteúdo, o formato de exportação recomendado é sempre o **PDF**. O processo consiste em selecionar a opção de exportar, escolher o formato PDF e, em seguida, exportar a "visualização atual" ou "exportar tudo".

## Exportando Bases de Dados

Quando o conteúdo é uma base de dados, o processo de exportação requer mais atenção para garantir que todos os dados sejam extraídos corretamente para uso posterior em outras ferramentas, como o "chat EPT".

### Passo a Passo para Exportação de Base de Dados

1.  **Garantir a Visualização Correta:** Antes de iniciar a exportação, é crucial certificar-se de que a visualização na tela é a "visualização geral". Isso garante que **todos os dados** da base sejam incluídos, e não apenas um subconjunto filtrado. O conteúdo enfatiza que se deve sempre selecionar a visualização geral.

2.  **Iniciar a Exportação:** Clique na opção para exportar a base de dados.

3.  **Configurar o Formato:** Altere o formato de exportação padrão (PDF) para **HTML**.

4.  **Definir as Opções de Exportação:** Configure a exportação da seguinte maneira:
    *   Formato: **HTML**
    *   Escopo: **Visualização atual** (que deve ser a visualização geral, conforme o passo 1)
    *   Conteúdo: Selecionar a opção para **"incluir conteúdo tudo"**.

5.  **Executar a Exportação:** Clique no botão para exportar.

### Manipulação do Arquivo Exportado

Após a exportação, o arquivo será baixado em formato **ZIP**. Para acessar os dados, siga os seguintes passos:

1.  O arquivo baixado será um arquivo compactado `.zip`.
2.  Abra o arquivo ZIP para extrair seu conteúdo. Dentro, haverá uma pasta.
3.  Ao abrir a pasta, você encontrará pelo menos dois arquivos. Um deles contém informações sobre toda a estrutura do "motionção", incluindo todas as bases de dados.
4.  O arquivo correto a ser utilizado é o que corresponde especificamente à visualização que foi exportada. Este arquivo estará localizado dentro de um caminho descrito como "particular e compartilhado".
5.  É este documento específico que contém os dados a serem levados para análise no "chat EPT".

## Ferramentas Mencionadas

*   **Ocean:** A plataforma de origem da qual os dados e textos são exportados. Ela permite a criação tanto de páginas de texto simples quanto de bases de dados complexas.
*   **chat EPT:** A ferramenta de destino para a qual os dados da base de dados exportada (em formato HTML) são levados para processamento ou análise.
