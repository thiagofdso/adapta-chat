# Compartilhamento, Permissões e Gerenciamento no Notion

O material apresentado detalha múltiplos aspectos do uso do Notion, com foco em compartilhamento, permissões de acesso, gerenciamento de planos e utilização de templates específicos para clientes e equipes.

## Níveis de Acesso e Colaboração

O conteúdo explora as diferentes formas de compartilhar o acesso dentro do Notion, destacando a diferença entre adicionar um membro à equipe e convidar um "membro convidado".

### Tipos de Permissão para Convidados

Ao compartilhar uma página, existem três níveis de permissão principais que podem ser concedidos a um convidado:

*   **Pode visualizar:** O convidado apenas enxerga o conteúdo, sem a capacidade de interagir ou deixar comentários.
*   **Pode comentar:** Considerado o ideal para clientes, pois permite que eles visualizem todo o conteúdo e adicionem comentários para aprovação ou feedback, sem poder editar a estrutura.
*   **Pode editar:** Permite que o convidado altere o conteúdo. Essa opção, no entanto, só está liberada em planos pagos, como o "Plus".

A principal vantagem de segurança ao usar a permissão "Pode comentar" é que o convidado não consegue acessar ou modificar os filtros de uma base de dados. Isso impede que ele veja informações de outros clientes ou dados que não lhe dizem respeito, mesmo que estejam na mesma base de dados.

> É sugerido ter um e-mail secundário para realizar testes e verificar exatamente o que um usuário convidado consegue visualizar, garantindo que o compartilhamento está sendo feito de forma segura.

## Publicando Páginas na Web

Uma funcionalidade destacada é a capacidade de "Publicar" uma página do Notion na web. Ao fazer isso, a página se torna um site acessível através de um link público.

*   **Caso de Uso (Portfólio):** Um exemplo prático demonstrado foi a criação de um site pessoal/portfólio. Uma página do Notion contendo informações de trabalho e serviços foi publicada, transformando-se em um site funcional sem a necessidade de contratar um desenvolvedor ou pagar por uma plataforma de criação de sites.
*   **Compartilhamento de Templates:** Esse método também é utilizado para compartilhar templates. A página é publicada na web e o link é enviado para que outras pessoas possam acessá-la.

### Consideração de Segurança ao Publicar

Ao publicar uma página que serve como amostra ou portfólio, é crucial desativar a opção **"Permitir duplicar"** antes de publicar. Se essa opção permanecer ativa, qualquer pessoa com o link poderá copiar todo o sistema ou conteúdo para o seu próprio espaço de trabalho do Notion.

## Comparativo de Planos: Free vs. Plus

O material detalha as limitações e vantagens dos planos Free e Plus do Notion.

### Plano Free

*   **Limite de Blocos:** Possui um limite de 1.000 blocos quando se convida outra pessoa para o workspace. Para uso estritamente pessoal (um único usuário), os blocos são ilimitados.
*   **Convidados:** Permite até 10 convidados, mas o limite de 1.000 blocos é ativado assim que alguém é convidado.
*   **Upload de Arquivos:** Limite de 5 MB por arquivo, o que é considerado muito baixo para imagens de alta definição ou vídeos.
*   **Histórico de Versões:** Salva o histórico de alterações de uma página por apenas 7 dias.

### Plano Plus

*   **Blocos e Upload:** Não há limite de blocos ou de tamanho para upload de arquivos.
*   **Convidados:** O limite aumenta para 100 convidados.
*   **Histórico de Versões:** O histórico de alterações é estendido para 30 dias.
*   **Outras Vantagens:** O plano pago oferece benefícios adicionais como automações, gráficos ilimitados e mais níveis de permissão.
*   **Valores Mencionados:** Os preços citados foram de 12 dólares por mês (cobrança mensal) ou 10 dólares por mês (cobrança anual).

## Processos Essenciais no Notion

### Duplicação de Templates

O processo de duplicar um template ou uma página compartilhada é simples:
1.  Abrir o link da página a ser duplicada.
2.  Clicar no botão **"Duplicar"**, localizado no canto superior direito.
3.  O Notion solicitará que você escolha em qual dos seus espaços de trabalho o template deve ser adicionado.
4.  Após a seleção, o conteúdo é copiado para o seu Notion.

### Restauração de Páginas

Existem duas maneiras principais de recuperar conteúdos ou versões anteriores:

1.  **Lixeira:** Ao apagar uma página ou um item de uma base de dados, ele é movido para a **"Lixeira"**. A partir de lá, é possível restaurá-lo.
2.  **Histórico de Versões:** Dentro de uma página, é possível acessar o histórico de todas as alterações feitas e restaurar para uma versão anterior, respeitando o limite de dias do seu plano (7 no Free, 30 no Plus).

## Compartilhamento com Clientes

Um dos focos centrais é o processo detalhado e seguro para compartilhar o andamento de projetos com clientes.

### Passo a Passo: O Processo Padrão

1.  **Compartilhar as Bases de Dados:** É necessário compartilhar três bases de dados específicas com o cliente, sempre com a permissão **"Pode comentar"**:
    *   `Clientes`
    *   `Conteúdos`
    *   `Linhas Editoriais`
2.  **Verificar Acesso Restrito:** Após compartilhar as bases, é crucial verificar se o cliente **NÃO** ganhou acesso à página principal de **"Gestão de Conteúdo"** (a área de produção). Se o e-mail do cliente aparecer na lista de convidados desta página, ele deve ser removido. Isso impede que ele veja conteúdos de outros clientes.
3.  **Enviar o Link Direto:** Como as bases de dados são filtradas, o cliente não conseguirá ver sua própria página de cliente diretamente. É preciso copiar o link da página específica daquele cliente e enviá-lo (por WhatsApp, por exemplo).
4.  **Instruir o Cliente:** Ao receber o link, o cliente deve ser instruído a favoritar a página em seu Notion para não precisar do link toda vez que for acessá-la.

### Dica de Otimização: Centralizando o Compartilhamento

Para simplificar o processo de compartilhamento, especialmente ao lidar com muitos clientes, é sugerida uma otimização:

1.  Crie uma nova página chamada **"Compartilhamento com Clientes"**.
2.  Mova as três bases de dados (`Clientes`, `Conteúdos` e `Linhas Editoriais`) para dentro desta nova página.
3.  Em vez de compartilhar as três bases individualmente, agora você compartilha apenas essa única página **"Compartilhamento com Clientes"** com o cliente.

Isso reduz o trabalho manual de três compartilhamentos para apenas um, embora os outros passos (verificar o acesso à "Gestão de Conteúdo" e enviar o link direto da página do cliente) permaneçam os mesmos.

## Gestão de Equipe e Visualizações

Para equipes onde cada membro tem uma função diferente (designer, copywriter, etc.), é possível criar visualizações filtradas para que cada um veja apenas as tarefas que lhe competem.

O método recomendado é criar páginas por **função**, e não por pessoa:

1.  Crie uma nova página, por exemplo, **"Design"**.
2.  Dentro dela, crie uma **visualização vinculada (linked view)** da base de dados principal de conteúdos.
3.  Configure a visualização (por exemplo, em formato de quadro - "Kanban").
4.  Aplique um **filtro** por "Fase", mostrando apenas as etapas relevantes para aquela função (ex: "Fazer Design", "Refazer Design", "Aprovar Arte").
5.  É possível adicionar mais filtros, como por cliente ou por responsável ("Criado por"), para refinar ainda mais a visualização.

## Utilização do Template GESP

O GESP é um template mais complexo para gerenciamento de estratégias.

### Como Iniciar e Gerenciar Estratégias

*   Ao clicar no botão **"Nova Estratégia"**, um novo item é criado, mas pode não aparecer imediatamente no painel principal.
*   Isso ocorre devido a um filtro: a visualização principal exibe apenas estratégias com status como "Briefing" ou "Executar", enquanto uma nova estratégia é criada com o status "Em espera". É preciso alterar o status para que ela se torne visível.
*   Todos os itens criados, mesmo que não visíveis, estão armazenados na base de dados central do template.
*   Dentro de uma estratégia, existem botões para gerar automaticamente listas de tarefas pré-definidas.

### Utilizando Tarefas e Prompts de IA

*   Muitas tarefas no GESP contêm links que abrem diretamente o ChatGPT para executar uma ação específica.
*   Alguns itens não possuem um link, mas sim um **prompt** de texto. Nesses casos, o usuário deve copiar o prompt (`Ctrl+C`) e colá-lo (`Ctrl+V`) em uma nova conversa no ChatGPT.
*   Se um prompt estiver faltando, o conteúdo sugere que se pode pedir ao próprio ChatGPT para gerar um prompt para a finalidade desejada.
