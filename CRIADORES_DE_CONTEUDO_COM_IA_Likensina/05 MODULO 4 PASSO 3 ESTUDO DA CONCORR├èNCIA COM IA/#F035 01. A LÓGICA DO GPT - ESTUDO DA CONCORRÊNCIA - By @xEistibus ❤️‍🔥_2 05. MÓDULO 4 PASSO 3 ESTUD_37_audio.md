# Estratégia de Pesquisa de Concorrência com IA

O conteúdo apresenta uma metodologia para realizar a pesquisa de concorrência de uma estratégia utilizando Inteligência Artificial. O processo é descrito como extenso, envolvendo o uso de múltiplos chats e "agentes intermediários" que criam inputs para serem utilizados em um chat GPT principal, permitindo que a IA se oriente melhor durante a análise.

## Lógica Geral e GPTs Utilizados

A estratégia geral é dividida em etapas sequenciais, cada uma utilizando um tipo específico de GPT (agente de IA) para construir a análise progressivamente.

A lógica geral segue a seguinte ordem:
1.  **Criação dos Termos do Projeto:** Geração de palavras-chave e expressões do nicho que definem o universo temático do projeto.
2.  **Criação dos Critérios de Concorrentes:** Definição do que caracteriza um concorrente relevante para o projeto.
3.  **Pesquisa de Concorrência:** Com os insumos anteriores, a IA realiza a busca e gera uma lista de concorrentes.
4.  **Análise dos Principais Concorrentes:** Análise detalhada de cada concorrente principal da lista gerada.
5.  **Análise SWOT do Projeto:** Comparação do projeto com a análise dos concorrentes para identificar forças, fraquezas, oportunidades e ameaças.

### Ferramentas Mencionadas
O material menciona o uso de diferentes tipos de GPTs e ferramentas para executar o processo:

-   **GPT Custom (Personalizado):** Utilizado para tarefas que não exigem acesso externo à internet, como a geração dos "Termos do Projeto", dos "Critérios de Concorrência" e da "Análise SWOT". São agentes próprios.
-   **Deep Research:** Um GPT específico utilizado para tarefas que demandam um alto volume de processamento de informações e acesso à web, como a "Pesquisa da Concorrência" e a "Análise de Concorrência".
-   **Miro:** A ferramenta visual utilizada na apresentação para explicar a lógica do fluxo de trabalho.
-   **Notion:** O local onde a lista de GPTs de concorrência está armazenada e organizada.

## Passo a Passo do Processo de Análise

O processo completo é detalhado em quatro etapas principais, desde a definição do escopo da pesquisa até a criação da matriz SWOT final.

### 1. Criação dos Termos do Projeto

O primeiro passo é utilizar um GPT customizado para gerar os "termos do projeto". O objetivo é criar uma lista de palavras-chave e expressões relevantes para o nicho, que não são baseadas em volume de pesquisa, mas sim em sua relação com o universo temático. Isso ajuda a IA a focar sua pesquisa no lugar certo.

O processo deste GPT opera em três camadas:
1.  **Geração dos Termos Raiz:** Identificação de 3 a 5 termos principais que guiam o projeto. São os tópicos genéricos que o projeto aborda. O exemplo dado é de um projeto imobiliário, com termos como "construção para venda", "mercado imobiliário" e "investimento em imóveis".
    -   Esses termos podem ser sugeridos pela IA e validados pelo usuário. Se não forem validados, a IA gera novos termos. Alternativamente, o usuário pode fornecer os termos raiz diretamente.
2.  **Geração dos Termos Derivados:** A partir dos termos raiz validados, a IA cria termos mais específicos e nichados.
3.  **Geração dos Termos de Cauda Longa:** Com base nos termos derivados, são gerados termos muito específicos ("o nicho do nicho") para fornecer uma visão detalhada do universo temático do projeto.

### 2. Definição dos Critérios de Concorrência

Com os termos do projeto definidos, o próximo passo é usar outro agente customizado para criar os "critérios de concorrentes". Isso estabelece uma definição clara do que faz uma pessoa ou empresa ser considerada uma concorrente.

Para isso, o GPT recebe três tipos de inputs:
-   Os **Termos do Projeto** (o universo temático).
-   Os **DNAs do projeto** (características essenciais do projeto ou do especialista).
-   Os **Objetivos do projeto**.

A IA então executa o seguinte processo:
-   **Análise do Universo Temático:** Entende que os concorrentes devem atuar dentro dos termos do projeto.
-   **Síntese com o DNA:** Compara os potenciais concorrentes com o DNA do projeto para excluir aqueles que estão fora do escopo (ex: um portal de conteúdo que não vende produtos, caso o projeto seja focado em vendas).
-   **Alinhamento com Objetivos:** Cruza as informações com os objetivos do projeto para focar em concorrentes que têm o potencial de impactar negativamente o negócio.

O resultado é uma lista de critérios que define um concorrente. Após essa etapa, o usuário deve **definir manualmente uma lista de "concorrentes conhecidos"**. Essa lista serve como um parâmetro para a IA realizar uma busca "lookalike", ou seja, encontrar outros perfis similares.

### 3. Pesquisa de Concorrência

Com os termos, os critérios e a lista de concorrentes conhecidos em mãos, a pesquisa é executada utilizando o GPT **Deep Research**.

A lógica de operação é a seguinte:
1.  **Vasculhamento do Universo Temático:** A IA começa buscando conteúdos e criadores que utilizam as palavras-chave definidas nos termos do projeto.
2.  **Busca por Similares (Lookalike):** A IA usa a lista de "concorrentes conhecidos" como parâmetro para identificar outros perfis similares e relevantes, evitando selecionar perfis aleatórios.
3.  **Verificação com Critérios:** Os concorrentes similares encontrados são filtrados com base nos "critérios de concorrência" previamente definidos para verificar se eles de fato se qualificam como concorrentes.
4.  **Análise de Congruência:** Os concorrentes que passam pelo filtro anterior são então verificados em relação ao DNA e aos objetivos do projeto para garantir um alinhamento mínimo.

O resultado final desta etapa é uma **lista final de concorrentes** validada.

### 4. Análise Detalhada e Matriz SWOT

A etapa final consiste em analisar a lista gerada e compilar a análise SWOT.

1.  **Análise Individual dos Concorrentes:**
    -   Pega-se a lista final e, usando o **Deep Research**, analisa-se um concorrente por vez (os 5 ou 10 principais, conforme a pertinência).
    -   É crucial que o próprio projeto (ou o projeto do cliente) também seja analisado pelo mesmo GPT para criar um documento de análise interna.
2.  **Criação da Matriz SWOT:**
    -   As duas informações geradas — a **análise dos concorrentes** e a **análise do próprio projeto** — são inseridas em um GPT customizado para a análise SWOT.
    -   Este GPT compara os dois documentos para criar a matriz SWOT, identificando:
        -   **Forças (Strengths):** Pontos fortes do projeto.
        -   **Fraquezas (Weaknesses):** Pontos fracos do projeto.
        -   **Oportunidades (Opportunities):** Oportunidades de mercado.
        -   **Ameaças (Threats):** Ameaças representadas pelos concorrentes.

Ao final deste fluxo, a análise completa da concorrência está concluída.
