# Extração de Inputs para a Criação do DNA do Conteúdo

O material apresenta a base para construir o "DNA do conteúdo" com Inteligência Artificial, que se inicia com a inserção de bons inputs no Chat GPT. Esses inputs formam o "DNA da empresa" e o "DNA do especialista", que, por sua vez, resultam no "DNA do conteúdo". A seguir, são detalhados os métodos para coletar e extrair esses inputs.

## Os Três Métodos de Extração de Inputs

Existem três métodos distintos para extrair as informações necessárias para alimentar a IA e iniciar a criação dos DNAs: o Interpretativo, o Guiado e o Autônomo.

### 1. Método Interpretativo

Este método é recomendado em duas situações específicas:

*   **Para estratégia própria:** Se você está desenvolvendo uma estratégia para si mesmo ou para seu próprio negócio, este é o método a ser seguido, pois os outros não se aplicarão.
*   **Para clientes com baixo grau de consciência:** Se você é um profissional de marketing criando uma estratégia para um cliente que possui pouca clareza ou consciência sobre o próprio projeto.

**Como funciona:**
O processo consiste em marcar uma reunião (call) com o cliente e fazer diretamente as perguntas que compõem o DNA (as 11 do DNA de especialista e as 10 do DNA da empresa). Como o cliente tem baixa clareza, as respostas podem não ser diretas ou organizadas. O seu papel na reunião é ajudá-lo a encontrar essa clareza.

Após a reunião, em vez de usar as palavras exatas do cliente, você utilizará a **sua própria interpretação** do que foi discutido. Você irá processar as informações e responder às perguntas no Chat GPT como se fosse o estrategista do cliente, com base no seu entendimento. Isso é feito porque as respostas diretas de um cliente com baixa consciência tendem a ser desorganizadas e não constituem um bom input para a IA.

Na prática, ao usar o agente de DNA no Chat GPT, você mesmo responderá às perguntas (seja por áudio ou texto) com base na sua interpretação.

> **Ponto importante:** Caso esteja criando uma estratégia para si mesmo e não tenha clareza sobre como responder a uma pergunta, você pode pedir ao Chat GPT para "quebrar" a pergunta em outras menores, tornando a resposta mais fácil e tangível.

### 2. Método Guiado

Este método é aplicável quando se está criando uma estratégia para um cliente que possui um **grau de consciência médio**. Esse tipo de cliente já tem alguma clareza e noção sobre seu negócio, fornecendo respostas mais lineares, diretas e organizadas.

**Como funciona:**
Neste caso, as respostas do cliente são consideradas um bom input para a IA. O processo envolve:

1.  Marcar uma reunião com o cliente.
2.  **Transcrever** toda a conversa da reunião.
3.  Utilizar essa transcrição como input no Chat GPT.

Ao interagir com o agente de DNA, para cada pergunta feita pela IA, você deverá localizar a resposta correspondente no documento de transcrição e copiá-la para o chat. O conteúdo menciona que existe uma forma menos manual de realizar este processo com a própria IA, a ser detalhada posteriormente.

### 3. Método Autônomo

Recomendado para clientes com um **alto grau de consciência**, que já entendem muito bem seus projetos. O exemplo citado é o de um cliente chamado "Rafa", com quem este método foi utilizado.

**Como funciona:**
Neste cenário, uma reunião não é estritamente necessária. O fluxo é o seguinte:

1.  Envie todas as perguntas do DNA em um documento de texto para o cliente (via WhatsApp, por exemplo).
2.  Peça ao cliente para gravar **um único áudio** respondendo a todas as perguntas.
3.  Transcreva este áudio.
4.  Use a transcrição como input para a IA.

> **Hack de usabilidade:** Para facilitar o processo, instrua o cliente a, no mesmo áudio, enunciar a pergunta e, em seguida, fornecer a resposta. Isso evita o trabalho de transcrever múltiplos arquivos de áudio.

## Ferramentas Mencionadas para Transcrição

Para executar os métodos Guiado e Autônomo, a transcrição de áudios ou reuniões é fundamental. O material apresenta algumas ferramentas para essa finalidade.

### Google Meet (MIT)

Descrita como a forma mais fácil, rápida e gratuita de transcrever uma reunião. O processo dentro da ferramenta é:

1.  Durante a reunião no Google Meet, acesse as opções no canto da tela.
2.  Clique no botão **"começar a tomar notas"**.
3.  Certifique-se de que a opção **"transcrever na reunião também"** esteja ativa.

A ferramenta utilizará a IA do Google (Gemini) para não apenas transcrever toda a conversa, mas também para gerar insights, pontos de ação e uma ata resumida do encontro.

### Transcriptor

É uma ferramenta de transcrição que se destaca por sua integração com as principais plataformas de reunião:
*   Google Meet
*   Zoom
*   Microsoft Teams

### TurboScribe

É outra ferramenta de transcrição, mencionada como a mais utilizada no dia a dia pela equipe da apresentação. É apontada como sendo mais barata ("mais em conta") que o Transcriptor.

**Resumo do uso das ferramentas:**
*   Para transcrever **reuniões**, pode-se usar a funcionalidade nativa do Google Meet.
*   Para transcrever **áudios** (como os do método autônomo), as ferramentas recomendadas são o TurboScribe ou o Transcriptor.
