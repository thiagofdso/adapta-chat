# RFC 6902 (JSON Patch) GUIDANCE
- **add**: insere ou substitui valores. Quando o `path` aponta para um índice de array, o valor é inserido naquela posição (índices maiores que o tamanho atual são inválidos). Quando aponta para uma chave inexistente em objeto, cria-a; se já existir, substitui. O objeto da operação **deve** conter `value`. Exemplo compacto: `{"op":"add","path":"/sections/0/knowledges/-","value":{"id":99,"category":"conceito","name":"novo","description":"resumo","files":["aula.txt"],"knowledge_related":[]}}`.
- **replace**: substitui o valor no `path`. O alvo **deve** existir. Equivalente a remover e adicionar no mesmo local. Exemplo: `{"op":"replace","path":"/sections/0/title","value":"Titulo Atualizado"}`.
- Use `"-"` como índice apenas para anexar ao fim do array (ex.: `"/sections/0/knowledges/-"`). Para inserir em posição específica, o índice deve estar entre `0` e o tamanho atual da lista.
